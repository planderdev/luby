## 1. 서비스 개요

**루비AI**는 광고주(브랜드·소상공인)와 크리에이터(인플루언서)를 연결하는 **체험단 마케팅 SaaS**입니다.
AI가 캠페인 기획을 대신 작성하고 적합한 크리에이터를 추천하는 것이 핵심 차별점입니다.

```
광고주: 캠페인 등록(AI 보조) → 검수 → 모집 → 선정 → 콘텐츠 검수 → 성과
크리에이터: 캠페인 탐색 → 응모 → 선정 → 체험·콘텐츠 발행 → 제출 → 포인트 적립 → 현금 출금
운영자: 회원 승인 → 캠페인 검수 → 결제·정산 관리 → 플랫폼 통계
```

- **수익 모델**: 광고주 구독 (FREE / BUSINESS ₩1,800,000/월 / ENTERPRISE 상담)
- **포인트 경제**: 1P = 1원. 광고주가 캠페인에 건 포인트 → 콘텐츠 승인 시 크리에이터에게 지급 → 최소 10,000P부터 현금 출금
- **글로벌 지향**: 활동 지역 12개국 (한국·일본·미국·대만·태국·베트남·인도네시아·필리핀·싱가포르·말레이시아·홍콩·중국), 랜딩 3개 언어 (한국어/영어/중국어)

## 4. 핵심 플로우 상세

### 4.1 캠페인 라이프사이클

```
draft(초안) → pending_approval(검수중) → open(모집중) → closed(마감) → completed(완료)
                     ↓ 반려
                 cancelled
```
- 모집 마감일 경과 시 **pg_cron이 매시 정각 자동 마감** (open → closed) + 광고주 알림

### 4.2 콘텐츠 검수·포인트 지급 (원자적 처리)

```
선정(selected) → 크리에이터 콘텐츠 제출(submitted)
  → 광고주 승인: 제출 approved + 응모 completed + 포인트 지급 [한 트랜잭션]
  → 수정 요청: revision_requested(피드백) → 재제출 → 재검수
```

### 4.3 포인트 출금 (이중지출 방지)

```
신청: 잔액 잠금 → 검증(최소 1만P) → 즉시 차감 → 신청 생성 [한 트랜잭션]
처리: 운영자 지급 완료  또는  반려 → 포인트 자동 환불 + 사유 기록
```

### 4.4 결제 (스푸핑 방어)

```
주문 생성(금액은 서버가 plans 테이블에서 조회) → 토스 위젯 결제
→ 성공 리다이렉트 → 서버 승인: ① 본인 주문 확인 ② 금액=플랜 원가 대조
→ ③ 토스 승인 API 성공 시에만 ④ service_role로 결제 기록+구독 30일 부여 (멱등)
```

## 5. 알림 시스템

**DB 트리거 기반** — 앱 코드와 무관하게 이벤트 발생 시 자동 생성, 누락 없음.

| 이벤트 | 수신자 |
|---|---|
| 새 응모 접수 / 콘텐츠 제출·재제출 | 광고주 |
| 캠페인 승인·반려·모집 마감 | 광고주 |
| 선정/미선정 / 검수 결과(승인·수정요청) / 출금 처리 결과 | 크리에이터 |
| 새 캠페인 검수 요청 / 새 출금 신청 | 운영자 |

- **인앱**: 대시보드 벨 아이콘 + 미읽음 배지, 알림 목록 페이지, 모두 읽음 처리
- **이메일**: 알림 생성 → pg_net 웹훅 → `/api/notifications/email` → Resend 발송
  (RESEND_API_KEY 미설정 시 자동 no-op, 테스트 계정에는 미발송)

## 6. 보안 설계 원칙

1. **RLS 전면 적용** — 모든 테이블에 행 수준 보안. 본인 데이터만 접근, 운영자는 `is_operator()` 검증
2. **금전·상태 변경은 SECURITY DEFINER 함수 전용** — 포인트 지급, 출금 신청·처리, 검수 승인은 DB 함수가 소유권·잔액을 재검증 후 원자적 처리. 테이블 직접 조작 정책 없음 → 우회 불가
3. **서버 이중 검증** — 플랜 제한·결제 금액·필수값은 UI뿐 아니라 서버 액션에서도 차단
4. **권한 상승 차단** — 가입 시 역할 화이트리스트(advertiser/influencer만), 운영자는 DB에서만 지정
5. **비밀키 관리** — service_role·토스 시크릿은 서버 전용(Vercel Sensitive), 클라이언트 번들에 미포함
