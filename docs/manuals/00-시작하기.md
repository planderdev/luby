# Luby AI 가이드 — 시작하기

> 대상: 루비AI를 처음 쓰는 모든 분 · 최종 갱신 2026-08-23 · https://luby.im

## 1. 루비AI란
루비AI는 **글로벌 체험단 마케팅 플랫폼**입니다. 광고주(브랜드·자영업·대행사)가 캠페인을 열면 크리에이터가 응모하고, AI가 매칭·검수를 돕고, 콘텐츠 발행 후 포인트로 정산까지 한곳에서 끝납니다.

- **광고주**: 업종 한 줄만 적으면 AI가 캠페인 전체를 작성 → 운영팀 검수 → 모집 → 선정 → 콘텐츠 검수 → 성과 리포트
- **크리에이터**: 채널 등록 → 맞춤 캠페인 추천·즉시 알림 → 응모 → 체험·콘텐츠 → 포인트 → 1만P부터 계좌 정산
- **글로벌**: 한국·일본·대만·동남아·미국 등 12개 마켓, 인스타·유튜브·틱톡·블로그·샤오홍슈·Lemon8 등 8개 채널
- **공개 페이지**: 로그인 없이 보는 캠페인 페이지(`luby.im/c/…`)·크리에이터 프로필(`luby.im/p/…`)·모집중 디렉터리(`luby.im/c`)

## 2. 역할별 바로가기
| 나는… | 먼저 볼 문서 | 시작 링크 |
|---|---|---|
| 브랜드·자영업 광고주 | 광고주 가이드 → 시작하기 · 캠페인 만들기 | https://luby.im/signup?role=advertiser |
| 마케팅 대행사·실행사 | 광고주 가이드 + 대행사 가이드 | https://luby.im/signup?role=advertiser |
| 크리에이터·인플루언서 | 크리에이터 가이드 → 가입과 승인 | https://luby.im/creators |
| 운영자(루비 팀) | 운영자 가이드(운영자 로그인 시 표시) | https://luby.im/dashboard |

가입은 이메일 또는 소셜 로그인으로 3분이면 끝납니다. 광고주는 가입 즉시 활동할 수 있고, 크리에이터는 채널 검수 후(보통 24시간 이내) 응모할 수 있습니다.
