# Luby AI 광고주 매뉴얼 (브랜드 · 자영업)

> 대상: 캠페인을 열어 크리에이터를 모집하는 광고주 · 최종 갱신 2026-08-19 · https://luby.im
> 대행사·실행사는 이 매뉴얼 + [03-대행사-매뉴얼](03-대행사-매뉴얼.md)을 함께 보세요.

## 1. 시작하기

### 1-1. 가입
1. https://luby.im/signup 에서 **광고주** 선택 (또는 소셜 로그인 후 온보딩에서 역할 선택)
2. **광고주 유형**: `브랜드·자영업` / `마케팅 대행사·실행사` 중 선택
3. 회사·상호명, 사업자등록번호(숫자 10자리), 담당자 이름·연락처 입력 → 가입
4. 받은 메일함에서 **이메일 인증** 링크 클릭 → 대시보드 진입 (광고주는 즉시 활동 가능, 승인 대기 없음)

> 가입 직후 **환영 알림**과 함께 "첫 캠페인 만들기" 링크가 옵니다. FREE 플랜은 첫 캠페인 1건이 무료입니다.

### 1-2. 회사 프로필 채우기 — `대시보드 → 설정`
- 담당자 이름 · 프로필 사진(로고) · **광고주 유형** · 회사명 · 주요 업종 · 회사 소개 · 웹사이트
- **세금계산서 · 청구 정보**(대표자명·사업장 주소·세금계산서 수신 이메일) — BUSINESS 결제 시 세금계산서 발행에 사용됩니다. 미입력 시 담당자 이메일로 발행
- 설정 상단 **회사 프로필 완성도** 게이지의 "다음: ○○" 버튼을 따라가면 됩니다. 크리에이터는 응모 전 광고주 프로필(`/dashboard/advertisers/[id]`)을 보고 신뢰를 판단합니다.

### 1-3. 대시보드 홈 읽는 법
- 상단 카드: 등록 캠페인·모집중·현재 플랜. 아래 **오늘 할 일**에 선정 대기 응모자·검수 대기 콘텐츠·안 읽은 메시지·마감 임박·구독 만료·초안이 건수와 함께 뜹니다.
- **최근 30일 퍼널**(공개 캠페인이 하나라도 있으면 표시): 공개 페이지 방문(순 방문·조회) → 응모 → 선정 → 콘텐츠 발행을 단계별 전환율과 함께 보여주고, 유입 경로(QR 포스터·공유 링크·디렉터리·추천·직접)와 가장 많이 본 캠페인 링크가 붙습니다. 캠페인별 상세는 캠페인 상세 → 캠페인 성과에서 확인합니다.

## 2. 캠페인 만들기 — `대시보드 → 캠페인 → 새 캠페인`

### 2-1. AI에게 전부 맡기기 (권장, 약 20~40초)
1. STEP 1에서 **상호명**과 **업종 설명 한 줄**(예: "명동 K뷰티 편집숍, 중국·대만 관광객 60%") 입력
2. **AI에게 전부 맡기기** 클릭 → 진행 패널(경과 시간·단계 표시) → 제목·홍보유형·카테고리·채널·채널별 미션·키워드·모집 인원·제공 내역·포인트가 자동 채워짐
3. STEP 3 **모집 기간(시작·종료)**은 광고주가 직접 입력해야 합니다 (AI가 임의로 정하지 않음). 체험 기간·요일/시간·당일 예약·상시 모집 옵션도 여기서
4. 각 스텝을 훑어보며 수정 → STEP 5에서 **검수 요청** (또는 **초안 저장**)

> 채널에 **샤오홍슈(小红书)·Douyin·Lemon8**을 넣으면 AI가 현지어 형식(笔记·해시태그·중국어 키워드 병기)에 맞춰 미션을 씁니다. 중국·화교권 관광객 대상 매장·K뷰티·K푸드라면 샤오홍슈를 추천합니다.

### 2-2. 직접 작성
- 5단계 빌더: **기본 정보 → 홍보·채널·미션 → 체험 일정 → 모집 설정·키워드 → 제공 내역·포인트**. 스텝마다 "AI 추천" 버튼으로 해당 필드만 제안받을 수 있습니다.
- 필수값이 비면 저장 시 모달로 해당 스텝을 안내합니다.
- **벤치마크**: 4단계 모집 인원 아래에 같은 분야(표본이 3개 미만이면 플랫폼 전체)의 최근 180일 캠페인 기준 모집 인원 중앙값·평균 경쟁률·충원율·많이 쓰는 채널이, 5단계 포인트 아래에 포인트 중앙값과 보통 구간(25~75%)·승인율이 표시됩니다. 입력값이 구간을 벗어나면 "평균보다 낮은 편 — 응모가 적으면 포인트를 올려 보세요" 같은 짧은 코멘트가 붙습니다. 집계 수치만 보이고 다른 광고주의 개별 캠페인은 노출되지 않습니다.

### 2-3. 검수 → 모집 시작
- 검수 요청 후 운영자가 확인(보통 당일). **승인되면 알림·이메일**이 오고 캠페인 상태가 `모집중`이 됩니다
- **반려(수정 요청)** 시: 알림·이메일로 운영팀의 수정 요청 사항이 오고, 캠페인 상세 상단 빨간 배너에 같은 내용이 표시됩니다 → **"수정 후 다시 검수 요청"** → 빌더 상단에 요청 사항이 고정되어 보이며, 저장하면 자동으로 재검수 요청(N차)이 전달됩니다
- 상태: `초안 → 검수중 → 모집중 → 마감 → 완료` / `반려(수정 필요)` / `취소`
- **성과 리포트 공유** (대행사 → 클라이언트 보고): 캠페인 상세 "캠페인 성과" 섹션의 **리포트 공유** → 공유 링크 만들기 → `luby.im/r/…` 링크를 클라이언트·팀에 전달. 로그인 없이 열리며 열 때마다 최신 수치(모집 진행률·경쟁률·예상 도달·발행 콘텐츠·퍼널·채널별 도달·콘텐츠 링크)가 생성됩니다. 크리에이터 연락처·정산 정보는 포함되지 않고, "PDF로 저장" 버튼으로 인쇄/PDF 가능. 공유 끄기를 누르면 링크가 즉시 무효. BUSINESS 플랜은 **캠페인이 완료되면 AI 요약이 자동으로 1회 생성**되며, 같은 패널의 **AI 요약 → 요약 생성/다시 생성**을 누르면 집계를 바탕으로 결과 한 줄·해석·다음 제안이 작성되어 리포트 상단과 성과 섹션에 표시됩니다(수치가 바뀌면 "다시 생성")
- **모집중 캠페인 조정**: 캠페인 상세의 "모집 연장 · 인원 추가" 패널에서 **모집 마감 연장**과 **모집 인원 증원**만 가능합니다(응모자 보호를 위해 단축·감원·내용 수정은 잠깁니다). 내용을 바꾸려면 취소 후 복제해 다시 검수를 받아주세요

### 2-4. 수정 · 복제 · 취소
- **수정**(초안·검수중·반려 상태): 상세 상단 **수정** 버튼 → 빌더에 기존 값이 모두 채워진 채 열림 → 저장(초안) 또는 **검수 요청**. 반려된 캠페인은 **"수정 후 다시 요청"** 버튼으로 같은 캠페인을 고쳐 재요청합니다. 모집이 시작된 뒤에는 수정 대신 복제를 이용하세요
- **이 캠페인으로 새로 만들기**(상세 상단): 채널·미션·키워드·제공 내역·일정까지 프리필, 모집 기간만 새로 지정
- **캠페인 취소**(검수중·모집중·마감 상태): 응모자에게 취소 알림 발송, 대기 응모 자동 취소. 이미 포인트가 지급된 응모가 있으면 취소 불가(마감 유지). 응모자가 있는 캠페인은 삭제할 수 없습니다.

## 3. 모집 늘리기

### 3-1. 공유 링크 (로그인 없이 보이는 공개 페이지)
- 상세 상단 **공유 링크 ▾** → 한국어(KR) / English(EN) / 中文(CN) 중 선택해 복사 → 인스타·카톡·샤오홍슈·홈페이지에 붙이기
- 공개 페이지(`luby.im/c/…`)에는 미션·제공 내역·포인트·일정과 **"가입하고 응모하기"** 버튼이 있어 신규 크리에이터 유입이 바로 응모로 이어집니다.
- **매장용 QR 포스터**: 같은 팝오버의 **매장용 QR 포스터 A4 인쇄** → 캠페인 제목·업체명·혜택·포인트·모집 인원·마감·채널과 공개 페이지 QR이 담긴 A4 세로 포스터가 열립니다. `?lang=en`/`zh`로 영문·중문 버전도 가능. **인쇄 / PDF 저장** 버튼으로 바로 출력해 카운터·입구·테이블에 붙이면 방문 손님이 QR을 찍고 응모합니다(캠페인 소유주·운영자만 열 수 있음).
- **유입 경로 집계**: 공유 링크·QR 포스터·캠페인 디렉터리·크리에이터 추천 링크로 들어온 공개 페이지 조회가 자동으로 집계됩니다. 캠페인 상세 **캠페인 성과 → 진행 퍼널** 맨 위에 "공개 페이지 방문"(순 방문자)과 방문→응모 전환율, 아래에 유입 경로별 조회 수가 표시되고 공유 리포트·AI 요약에도 반영됩니다. 개인 정보는 저장하지 않으며(방문자는 매일 바뀌는 해시로만 구분), 내 캠페인을 내가 열어본 조회는 제외됩니다.

### 3-2. AI 크리에이터 매칭 · 초대 (BUSINESS)
- 상세 하단 **AI 매칭** → 적합도 점수·추천 이유가 붙은 후보 → **초대** 클릭. 크리에이터가 수락하면 자동 응모됩니다.

### 3-3. 크리에이터 검색 — `대시보드 → 크리에이터 찾기`
- 검색어(이름·소개) · 업종 · 지역 · 채널 · 팔로워 · 정렬(팔로워/완료 수/최신)
- **빠른 필터**: `Xiaohongshu` `Douyin` `Lemon8` `공개 프로필 있음`
- 카드 클릭 → 포트폴리오(채널·완료 이력) → **초대**(모집중 캠페인 선택)

## 4. 응모자 선정 → 체험 → 콘텐츠 검수 — 캠페인 상세

1. **응모자 목록**: 채널·팔로워·응모 메시지 확인 → `선정` / `미선정`. FREE 플랜은 응모자 10명까지 열람
2. 선정되면 크리에이터에게 알림. **채팅**(BUSINESS)으로 일정·안내 조율 (`대시보드 → 메시지`)
3. 크리에이터가 콘텐츠 URL을 제출하면 알림. 응모자 행의 **AI 사전 검수**로 채널 일치·미션 체크포인트를 먼저 확인
4. **승인** → 즉시 크리에이터에게 포인트 지급(원자적) · **수정 요청** → 피드백 전달 → 재제출 → 재검수
5. 선정자 전원이 승인되면(마감 후) 캠페인이 **자동 완료**되고 **성과 리포트 알림**(응모·선정·승인·지급 포인트·예상 도달)이 옵니다

> 3일 이상 검수가 밀리면 리마인더가, 마감 후 3일 이상 선정이 밀리면 "응모자 N명이 선정을 기다려요" 알림이 옵니다.

## 5. 성과 보기
- 캠페인 상세 **캠페인 성과** 카드: 모집 진행률·응모 경쟁률·예상 도달(선정 크리에이터 팔로워 합)·지급 포인트·퍼널·채널별 도달
- 캠페인 목록 카드 칩: `선정 대기 N` `응모 N` `선정 N/모집` `승인 N · 지급 P`

## 6. 구독·결제 — `대시보드 → 구독·결제`
- FREE: 첫 캠페인 1건 · 응모자 10명 열람 / BUSINESS: 캠페인 무제한 · AI 매칭·초대·채팅 · 응모자 무제한 / ENTERPRISE: 상담
- 결제는 토스페이먼츠 결제창(카드). 30일 구독, 만료 7일 전 알림, 만료 시 자동 FREE 전환
- 구독·결제 페이지 하단 **결제 내역**에서 건별 확인. 카드 결제는 카드 매출전표가 적격증빙이고, 세금계산서가 필요하면 **"세금계산서 요청"** → 설정의 세금계산서 정보로 운영팀이 발행 후 알림

## 7. 알림·이메일 설정 — `설정 → 이메일 알림`
- 인앱 알림은 항상 수신. 이메일은 **진행 알림 / 리마인더·추천** 두 카테고리를 각각 on/off. 모든 알림 메일 하단에 수신 거부 링크가 있습니다.

## 8. 자주 묻는 질문
- **캠페인이 검수중에서 안 넘어가요** → 운영자 검수 대기입니다. 반려 알림이 없다면 곧 처리됩니다.
- **응모자가 안 보여요(10명까지)** → FREE 플랜 제한입니다. BUSINESS로 업그레이드하세요.
- **AI 초안이 마음에 안 들어요** → 다시 누르면 새 초안이 나옵니다. 업종 설명을 구체적으로(위치·고객·핵심 상품·타깃 국가) 적을수록 좋아집니다.
- **모집 기간이 지났는데 응모가 계속돼요** → `상시 모집`이 켜져 있으면 자동 마감되지 않습니다. STEP 3에서 끄거나 캠페인 취소/마감을 이용하세요.

### 주간 성과 다이제스트
매주 **월요일 오전 9시** 지난주 캠페인 성과(새 응모·선정·콘텐츠 제출·승인, 이번 주 마감, 검수 대기, 완료 캠페인)를 알림·이메일 한 통으로 보내드립니다. 설정 > 이메일 수신 설정의 **다이제스트**에서 끌 수 있습니다.

### 응모자 AI 적합도 평가 (BUSINESS)
캠페인 상세 > 응모자 목록 우측 **AI 적합도 평가** 버튼을 누르면 대기 중인 응모자(최대 30명/회)를 캠페인 조건(요구 채널·분야·지역·보상 대비 팔로워·응모 메시지·체험 이력)과 대조해 0~100점과 근거, 선정 전 확인할 점(해외 배송 가능 여부 등)을 표시하고 점수순으로 정렬합니다. 새 응모가 들어오면 버튼이 다시 나타나고, "다시 평가"로 전체 재평가할 수 있습니다. 평가 후 **상위 N명 선정** 버튼으로 점수 순 일괄 선정(기본값: 남은 모집 인원)도 가능하며, 최종 판단은 광고주가 합니다.

### AI 사용 한도
AI 기능(캠페인 작성·매칭·응모자 적합도·콘텐츠 검수·응모 초안·리포트 요약)은 계정별 **월 한도**가 있습니다 — FREE 30회, BUSINESS 300회, ENTERPRISE 무제한. 매월 1일 초기화되며 결제·플랜 페이지에서 이번 달 사용량을 확인할 수 있습니다. 한도에 도달하면 안내가 표시되고 다음 달까지 AI 기능이 잠깁니다(수동 기능은 그대로).

### 푸시 알림
설정 > **푸시 알림 > 이 기기에서 켜기**를 누르면 앱을 닫아 둔 동안에도 응모·선정·검수 알림이 기기로 바로 옵니다(이메일 수신 설정의 카테고리가 푸시에도 동일 적용). Android·PC Chrome은 바로 되고, **iPhone은 Safari 공유 → 홈 화면에 추가로 설치한 루비AI 앱에서** 켤 수 있습니다. 기기별로 켜고 끌 수 있습니다.

### 캠페인 복제 + 지난 성과 반영 (AI)
캠페인 상세 > 복제로 새 캠페인을 만들면 1단계에 **"지난 성과 반영해 다시 제안"** 버튼이 나타납니다. 원본 캠페인의 응모 경쟁률·승인율·채널별 도달을 근거로 모집 인원·포인트·채널·미션을 조정한 초안을 만들고, 무엇을 왜 바꿨는지 2~4줄로 보여줍니다(예: "경쟁률 0.4:1로 낮아 포인트를 15,000→20,000P로 인상"). AI 월 한도에 포함됩니다. 캠페인이 **완료된 지 7일**이 지나도 새 캠페인을 만들지 않았다면 "다음 캠페인, 지난 성과를 반영해 제안해 드릴까요?" 알림이 한 번 오고, 링크를 누르면 이 화면으로 바로 들어옵니다(리마인더·추천 카테고리에서 끌 수 있음).
