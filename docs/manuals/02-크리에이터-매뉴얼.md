# Luby AI 크리에이터 매뉴얼

> 대상: 캠페인에 응모해 체험·콘텐츠 발행 후 포인트를 받는 크리에이터 · 최종 갱신 2026-08-19 · https://luby.im

## 1. 가입과 승인
1. https://luby.im/signup 에서 **크리에이터** 선택 (또는 Google/카카오로 계속하기 → 온보딩에서 크리에이터 선택)
2. 이름·닉네임, 활동 지역, 대표 채널(URL), 전문 분야(최대 3개) 입력 → 가입 → **이메일 인증**
3. 운영자가 채널·프로필을 검수한 뒤 **승인**(보통 24시간 이내). 승인 알림·이메일이 오면 응모할 수 있습니다. 승인 전에도 캠페인 둘러보기는 가능합니다.

## 2. 프로필 완성하기 — `대시보드 → 설정`
개요 홈과 설정 상단의 **프로필 완성도** 게이지를 100%로 만드세요. 완성도가 높을수록 추천·초대가 늘어납니다.

| 항목 | 위치 | 팁 |
|---|---|---|
| SNS 채널 (30%) | 설정 → 채널 (`#channels`) | 채널 종류를 고르면 URL·핸들 예시가 바뀝니다. **샤오홍슈**는 앱 프로필의 `小红书号`가 핸들, URL은 프로필 공유 링크(xhslink 단축 링크 가능) · Douyin은 `抖音号` · Lemon8은 `lemon8-app.com/@…`. 채널 종류와 다른 주소는 저장되지 않습니다 |
| 전문 분야 (25%) | 설정 → 전문 분야 (`#categories`) | 최대 3개. 내 분야 캠페인이 먼저 추천됩니다 |
| 팔로워 수 (15%) | 채널별 입력 | 광고주 필터·예상 도달 계산에 쓰입니다 |
| 한 줄 소개 (15%) | 설정 | 광고주가 선정할 때 가장 먼저 읽는 문장 (10자 이상) |
| 활동 지역 (10%) · 프로필 사진 (5%) | 설정 | 지역 기반 추천 · 사진 있는 프로필이 선정률이 높습니다 |

## 3. 캠페인 찾기 — `대시보드 → 캠페인`
- 기본 정렬 **추천순**(내 분야·지역·응모 여부 반영), `내 분야` `내 지역` `응모함` 배지 / 최신순·마감 임박순·포인트순, 업종·지역 필터
- 개요 홈 **"내게 맞는 캠페인"** 3개 · 이번 주 새 캠페인 수 · **내 분야 캠페인이 48시간 내 마감**되면 아침 알림
- **새 캠페인 즉시 알림**: 내 전문 분야(또는 내 활동 지역 + 내가 가진 채널)에 맞는 캠페인이 모집을 시작하면 바로 알림·푸시·이메일이 옵니다(하루 최대 1건, 나머지는 월요일 다이제스트에 모아서). 전문 분야·지역·채널을 채워둘수록 정확해지고, `설정 → 이메일 알림`의 **리마인더·추천**에서 끌 수 있습니다.
- 캠페인 상세: 미션(채널별)·제공 내역·모집 기간·포인트·광고주 프로필 링크
- 캠페인 상세 오른쪽 **선정 가능성** 카드: 경쟁률(응모/모집·D-day), 내 분야·지역·채널 일치 여부, 완료 이력과 함께 높음/보통/낮음 등급과 보완 팁(채널 등록·분야 추가·응모 메시지)을 보여줍니다. 참고용 추정이며 최종 선정은 광고주가 합니다

## 4. 응모 · 초대
1. 상세에서 **응모하기** → 응모 메시지(선택). **AI 초안** 버튼을 누르면 캠페인 미션과 내 프로필로 2~3문장이 채워집니다(수정 가능)
2. 응모 대기 중엔 **응모 취소** 가능. 같은 캠페인 중복 응모는 안 됩니다
3. 광고주가 초대하면 `대시보드 → 받은 초대`에서 **수락(자동 응모)** / 거절
4. 선정되면 알림·이메일 → 광고주와 **채팅**(`대시보드 → 메시지`)으로 일정 조율

## 5. 체험 → 콘텐츠 제출 → 검수 — `대시보드 → 내 응모`
1. 선정된 캠페인의 미션대로 콘텐츠 발행(**#광고 #협찬 등 경제적 대가 표기 필수**)
2. **콘텐츠 제출**: 발행 URL + 메모 → 광고주 검수
3. **승인** → 포인트 즉시 적립 / **수정 요청** → 피드백 확인 → 같은 화면에서 **재제출**
4. 체험 종료 후 제출이 없으면 리마인더가 옵니다

## 6. 포인트와 출금 — `대시보드 → 포인트`
- **보유 포인트**(1P = 1원) · **포인트 내역**: 콘텐츠 승인(+캠페인명) · 추천 보상 · 출금 · 출금 대기 · 반려 를 시간순으로
- **출금 신청**: 최소 10,000P, 은행·계좌·예금주 입력 → 신청 즉시 차감 → 운영자 확인 후 지급(반려 시 자동 환불·사유 표시)

## 7. 공개 프로필 · 친구 추천
- `설정 → 공개 프로필` 토글 ON → `luby.im/p/내ID` 링크(KR/EN/CN) — 이름·사진·소개·지역·분야·채널·완료 협업만 표시(이메일·연락처·정산 정보 비공개). 광고주·해외 브랜드에 포트폴리오로 보내세요
- `대시보드 → 내 포트폴리오`에서 PDF 저장, **QR 명함 A4 인쇄** → 명함 규격(90×55mm) 10장이 한 장에 나오고 QR을 찍으면 내 공개 프로필이 열립니다(공개 프로필 ON 필요). 매장 방문·행사·팝업에서 사장님께 바로 건네세요
- 공개 프로필이 켜져 있으면 **내 포트폴리오** 상단에 프로필 조회 수(총·순 방문·최근 7일)와 유입 경로(QR 명함 / 포트폴리오 링크 / 직접·검색)가 표시됩니다. 방문자는 매일 바뀌는 해시로만 구분해 개인 정보는 저장하지 않고, 내가 직접 본 조회는 빠집니다
- 캠페인 상세 **친구에게 공유** → 내 추천 링크(?ref) 복사. 링크로 가입한 친구가 **첫 체험을 완료하면 500P**(월 5명까지). 개요 홈 "내 추천 가입"에서 확인

## 8. 알림·앱처럼 쓰기
- 인앱 알림 + 이메일(진행 알림 / 리마인더·추천 각각 on/off, `설정 → 이메일 알림`)
- 모바일 브라우저에서 luby.im → **홈 화면에 추가** → 앱처럼 실행(바로가기: 캠페인·내 응모·알림)

## 9. 자주 묻는 질문
- **승인이 안 나요** → 채널 URL이 실제 프로필인지, 소개·분야가 채워졌는지 확인하세요. 24시간 넘게 대기 중이면 contact@plander.io
- **응모 버튼이 안 보여요** → 승인 전이거나 모집이 마감된 캠페인입니다
- **포인트가 안 들어왔어요** → 광고주 승인 후 적립됩니다. 내 응모에서 상태(제출됨/수정 요청/승인)를 확인하세요

### 주간 다이제스트
매주 **월요일 오전 9시** 내 분야·지역에 새로 열린 캠페인, 이번 주 마감, 응모 대기·제출 필요·검수 대기 건수, 지난주 승인·적립 포인트, 출금 가능 여부를 알림·이메일 한 통으로 받습니다. 설정 > 이메일 수신 설정의 **다이제스트**에서 끌 수 있습니다.

### 푸시 알림
설정 > **푸시 알림 > 이 기기에서 켜기**를 누르면 앱을 닫아 둔 동안에도 선정·승인·마감 알림이 기기로 바로 옵니다(이메일 수신 설정의 카테고리가 푸시에도 동일 적용). Android·PC Chrome은 바로 되고, **iPhone은 Safari 공유 → 홈 화면에 추가로 설치한 루비AI 앱에서** 켤 수 있습니다. 기기별로 켜고 끌 수 있습니다.

### 내 포트폴리오 (PDF)
메뉴 > **내 포트폴리오**에서 내 프로필·채널·분야·협업 이력을 브랜드에 보여줄 포트폴리오 형태로 보고 **PDF로 저장 · 인쇄**할 수 있습니다. 공개 프로필이 꺼져 있어도 본인은 볼 수 있고, 켜면 같은 화면을 링크(`luby.im/p/…`)로 공유할 수 있습니다.
