# Luby AI 마케팅 대행사 · 실행사 매뉴얼

> 대상: 여러 클라이언트의 체험단 캠페인을 대신 운영하는 에이전시 · 최종 갱신 2026-08-19 · [광고주 매뉴얼](01-광고주-매뉴얼.md)의 기능은 모두 동일하게 사용

## 1. 대행사로 가입
- 가입 시 광고주 유형에서 **마케팅 대행사 · 실행사** 선택 → 상호 칸이 **대행사명**으로 바뀝니다. 사업자등록번호는 대행사 것을 입력
- 이미 브랜드로 가입했다면 `설정 → 광고주 유형`에서 변경 가능. 프로필·운영자 화면에 "대행사" 배지가 붙습니다

## 2. 클라이언트별 캠페인 운영
- 캠페인의 **상호명(business_name)은 캠페인마다 따로** 입력 → 클라이언트 A/B/C 캠페인을 한 계정·한 대시보드에서 관리
- **복제**: 상세 → "이 캠페인으로 새로 만들기" → 채널·미션·제공 내역·일정 프리필 → 클라이언트 상호와 모집 기간만 바꿔 검수 요청
- **AI에게 전부 맡기기**에 클라이언트 업종 한 줄(위치·고객·핵심 상품·타깃 국가)만 넣으면 초안이 나옵니다

## 3. 크리에이터 소싱
- `크리에이터 찾기`: 업종·지역·채널·팔로워·정렬 + 빠른 필터 **Xiaohongshu / Douyin / Lemon8 / 공개 프로필 있음**
- 후보를 클라이언트에 공유할 땐 크리에이터 상세의 **공개 프로필 링크**(옵트인 크리에이터만) 사용
- BUSINESS: AI 매칭(적합도·이유) → 초대, 선정 후 채팅

## 4. 리스크 관리와 보고
- 검수 요청 시 운영자가 **AI 사전 점검**(광고 표기 누락·효능 과장·부당 요구)을 참고해 승인/반려 — 미션에 `#광고 #협찬` 표기를 미리 넣어두면 반려가 줄어듭니다
- 클라이언트 보고: 캠페인 성과 카드(퍼널·채널별 도달), 완료 시 **성과 리포트 알림**, 캠페인 목록 성과 칩, 공개 캠페인 페이지 링크(KR/EN/CN)

## 5. 플랜
- 여러 클라이언트를 동시에 운영하려면 **BUSINESS**(캠페인 무제한·AI 풀패키지·응모자 무제한·채팅) 이상이 필요합니다. 대량 운영·API·전담 매니저는 ENTERPRISE 상담(contact@plander.io)
