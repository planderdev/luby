## 0. 첫 로그인 체크리스트
1. https://luby.im/login 에서 본인 운영자 이메일로 로그인 → **설정 → 비밀번호 변경**으로 개인 비밀번호 설정(공통 초기 비밀번호는 즉시 교체)
2. **설정 → 이메일 알림**: `진행 알림 / 리마인더·추천 / 운영 다이제스트` 중 받을 종류 선택 (plander.io 메일함으로 실제 발송됨)
3. **설정 → 프로필 사진**(선택) — 크리에이터·광고주가 보는 알림 발신자는 시스템이므로 필수 아님
4. 모바일: luby.im 접속 → "홈 화면에 추가"(PWA) → 앱처럼 알림·검수 처리 가능

## 2. 회원 관리 — `/dashboard/operator/users`
- **인플루언서 탭 상단 '모집 중 캠페인 안내'**(2026-10-07): 승인된 크리에이터 중 내 채널 종류·분야·지역에 맞는 모집 중 캠페인이 있는데 아직 응모하지 않은 사람 수와 예시가 보입니다. **안내 보내기 → 발송 확인**을 누르면 앱 알림·푸시·이메일(리마인더 수신 설정을 따름)로 "내 채널에 맞는 모집 중 캠페인 N개"가 나갑니다. 같은 사람에게는 14일 안에 다시 가지 않고, 최근 7일 안에 새 캠페인 알림을 받은 사람은 제외됩니다. 새 캠페인이 여러 개 열린 뒤 한 번씩 눌러 주세요.
- 상단 **검색**(이름·이메일·회사명·사업자번호) + **운영 태그 필터**(사용 중인 태그 칩) + 탭 **승인 대기 / 전체 / 광고주 / 대행사 / 인플루언서**(각 인원 수). 행에 태그 칩 표시
- 이름 또는 "상세 →" 클릭 → **회원 상세 페이지**: 역할별 정보(사업자 정보·플랜 / 지역·소개·분야·채널·포인트), 캠페인 또는 응모·출금 이력, 추천인, 이 회원에 대한 운영 기록, 최근 알림, 승인/해제 버튼. 광고주면 "대신 만들기"·공개 프로필, 크리에이터면 포트폴리오·공개 프로필 링크
- **플랜 강제 설정(총운영관리자 전용)**: 광고주·대행사 회원 상세의 사업자 정보 아래 **플랜 강제 설정** → FREE/BUSINESS/ENTERPRISE 선택 → 기간(30일·90일·1년·무기한·날짜 지정, FREE 는 기간 없음) → **변경 사유(필수)** → 적용. 결제 없이 바로 바뀌고, 운영 기록에 "플랜 강제 설정 · 이전 → 이후 · 사유"로 남습니다. "광고주에게 알림 보내기"를 켜 두면 "BUSINESS 플랜이 적용되었어요(○월 ○일까지)" 알림·메일이 갑니다(사유는 광고주에게 보이지 않음). 파트너 무상 제공, 결제 오류 보상, 환불 후 FREE 전환 등에 쓰세요. 총운영관리자는 admin@luby.im·이동욱 계정이며, 다른 운영자 화면에는 이 버튼이 보이지 않습니다(DB에서도 거절). 만료일이 지나면 평소처럼 FREE 로 돌아가고 만료 3일 전 알림이 갑니다
- 상세 페이지의 **운영 태그**(VIP·주의·파트너 등, 회원에게 비공개, 헤더에 표시)와 **운영 메모**(상담 이력, 상단 고정 가능, 운영자끼리 공유·회원 비공개)로 인수인계와 응대 맥락을 남기세요. 태그 변경은 운영 기록에 남습니다
- 행 정보: 광고주 → 회사명·사업자번호·**대행사 배지**·담당자 / 크리에이터 → 지역·채널 수·총 팔로워·소개 / 추천인 유무
- **미로그인 탭**: 두 묶음으로 나뉩니다. ① **이메일 미인증 가입자** — 직접 가입했지만 인증 링크를 안 누른 회원. "인증 메일 다시 보내기"로 가입 인증 메일을 재발송합니다(2026-10-07 이후 가입자는 24시간 뒤 자동 1회). ② **초대 후 미로그인** — 일괄 등록·초대 계정. "초대 메일 일괄 발송"으로 비밀번호 설정 링크를 보냅니다. 발송 한도에 걸리면 중단되니 잠시 후 다시 보내세요.
- **승인**: 채널 URL이 실제 프로필인지(종류와 도메인이 맞는지), 소개·전문 분야가 있는지 확인 → 승인 버튼. (2026-09-05부터 크리에이터 가입 시 채널 URL이 **필수**라 새 가입자는 항상 채널이 있습니다. "채널 미등록"으로 남아 있는 회원은 그 이전 가입자이며, 매일 아침 채널 등록 안내 메일이 자동 발송됩니다.) 승인 대기가 많으면 **일괄 승인** 사용. 승인 즉시 크리에이터에게 "계정 승인" 알림·이메일
- 광고주는 가입 즉시 활동 가능(자동 승인). 문제 계정은 승인 해제로 활동 중지(캠페인 생성·응모 불가)
- **회원 추가(초대)**: 회원 관리 상단 **회원 추가** → `광고주(브랜드·자영업) / 대행사·실행사 / 크리에이터` 선택 → 이메일·이름(+회사명·사업자번호 또는 활동 지역) → **계정 전달 방식** 선택: ① **초대 메일**(비밀번호 설정 링크, Luby 템플릿) ② **임시 비밀번호 생성**(랜덤 비밀번호를 화면에서 복사해 직접 전달) ③ **비밀번호 직접 지정**(운영자가 정한 비밀번호로 즉시 생성, 8자 이상 영문+숫자) — ②③은 화면을 닫으면 비밀번호를 다시 볼 수 없으니 바로 전달하고 첫 로그인 후 변경을 안내. 운영자가 추가한 크리에이터는 바로 승인 상태. 운영 기록에 남음
- **엑셀로 내려받기**: 회원 관리 상단 버튼 → 현재 탭(전체/광고주/대행사/인플루언서) 기준 회원 CSV(엑셀 호환: 역할·연락처·승인·회사/사업자/대표자/주소/세금계산서 이메일·플랜·지역·채널·팔로워·분야·포인트·공개프로필·태그)
- **엑셀로 등록하기**: ① "템플릿 내려받기"로 양식 받기(역할·이메일·이름·연락처·회사명·사업자등록번호·활동지역·대표채널·채널URL·전문분야(;구분)·비밀번호) ② 채워서 업로드(CSV/XLSX, 300명까지) ③ **검증 미리보기**에서 오류 행 확인(이메일 형식·중복·기가입·사업자번호·지역/채널/분야 이름 인식) ④ 비밀번호 열이 빈 행의 처리 방식(초대 메일 / 임시 비밀번호) 선택 → **등록 실행** ⑤ **결과 CSV 내려받기** — 임시·지정 비밀번호는 이 파일에만 남으니 즉시 전달
- 운영자 계정은 셀프 가입으로 만들 수 없음(권한 상승 차단) — 추가 운영자는 개발팀이 생성

### 미로그인 회원 되살리기 — `회원 관리 → 미로그인` 탭
엑셀·회원 추가로 **일괄 등록한 계정은 안내 메일이 나가지 않습니다.** 그래서 상대는 로그인할 방법이 없고, 우리 쪽에서는 "가입은 했는데 아무것도 안 한 회원"처럼 보입니다. 미로그인 탭에서 대상자를 확인하고 **[N명에게 보내기]** 로 비밀번호 설정 링크를 한 번에 보내세요(확인 단계가 한 번 있고, 실제 메일이 나갑니다). 개별 회원 카드의 **[초대 메일 보내기]** 로 한 명씩 보낼 수도 있습니다. 메일 발송 한도에 걸리면 그 지점에서 멈추고 몇 건 나갔는지 알려주므로, 잠시 후 남은 인원에게 다시 보내면 됩니다. 상대가 로그인하면 목록에서 자동으로 빠집니다.

### 메일 반송 회원 — `회원 관리 → 메일 반송` 탭
없는 주소라 반송된 회원입니다. 메일 서비스(Resend)가 이 주소로 가는 메일을 **모두 차단**하므로 초대·인증·알림이 하나도 닿지 않습니다. 차단 목록은 매일 **09:10** 자동으로 가져오고, 탭 상단 **지금 동기화**로 바로 갱신할 수 있습니다.
- **목록 배지**: 회원 카드와 회원 상세의 이메일 옆에 "메일 반송"이 붙습니다.
- **고치는 법**: 회원 상세에서 실제 이메일을 넣고 **바꾸기** → 로그인 이메일이 바뀌고(인증 완료 상태), 메모에 변경 기록이 남습니다. 한 번도 로그인하지 않은 회원이면 이어서 **초대 메일 재발송**으로 비밀번호 설정 링크를 보내세요. 오타로 보이는 주소(gamil·.con 등)나 이미 다른 회원이 쓰는 주소, 반송 목록에 있는 주소는 거절됩니다.
- **일괄 발송에서 자동 제외**: 미로그인 탭의 초대·인증 메일 일괄 발송은 반송 회원과 **오타 주소(gamil.com·naver.con 등)·메일을 받을 수 없는 도메인**을 빼고 보내며, 단건 재발송도 막습니다(보내면 바로 반송돼 발신 평판만 떨어집니다). 미로그인 탭에서는 이런 회원에게 "주소 확인" 표시가 붙고, 누르면 회원 상세로 가서 실제 이메일로 바꿀 수 있습니다. 미인증 회원은 이메일을 바꾸면 인증된 상태가 되므로 가입 때 정한 비밀번호로 바로 로그인할 수 있습니다.
- **[대신 확인] 알림**: 메일이 반송됐거나 **한 번도 로그인하지 않은 광고주**에게 새 응모·선정 대기·콘텐츠 제출·검수 대기·메시지·초대 수락·모집 마감 알림이 생기면, 운영자 전원에게 "[대신 확인] 광고주명 — 원래 제목" 알림(앱·푸시·메일)이 함께 갑니다. 운영자가 대신 처리하거나 광고주에게 전화로 알려 주세요. 같은 내용은 12시간에 한 번만 옵니다.
- 차단을 풀면(Resend 에서 해제) 없는 주소로 다시 반송돼 발신 평판만 떨어집니다. **해제하지 말고 주소를 바꾸세요.**

## 2-0. 채널 본인 인증 요청 — 회원 관리 상단 **채널 인증 요청 N건**
- 크리에이터가 채널 소개란에 `LUBY-XXXXXX` 코드를 넣고 프로필 캡처를 올리면 요청이 들어옵니다(운영자 알림 ‘채널 인증 요청’). 캡처는 비공개 저장소에 있고 여기서만(1시간짜리 링크) 볼 수 있어요
- **확인할 것**: ① 캡처의 채널 소개란에 **요청에 적힌 코드**가 보이는지 ② 캡처의 계정이 등록한 채널(링크)과 같은지 ③ 화면의 **팔로워 수** — 신고 숫자와 다르면 ‘확인한 팔로워’ 칸을 캡처의 숫자로 고쳐 **승인**
- **승인** → 채널에 ‘✓ 운영자 확인’, 팔로워 수 확정, 크리에이터 알림 · **반려** → 빠른 사유(코드 안 보임·팔로워 다름·계정 다름·흐림, 영문·중문 크리에이터에게 번역돼 전달) 또는 직접 입력 → 크리에이터 알림. 둘 다 운영 기록에 남음
- **유튜브**는 YouTube API 키(`YOUTUBE_API_KEY`)가 있으면 크리에이터가 직접 ‘확인하기’로 자동 인증되고 구독자 수가 매주(월 10:30 KST) 갱신돼 여기로 오지 않습니다. 키가 없으면 유튜브도 캡처 요청으로 옵니다
- 광고주에게는 크리에이터 프로필·응모자 목록·공개 프로필에 ‘자동 확인 / 운영자 확인 / 미인증(본인 입력)’으로 보입니다

## 2-1. 캠페인 풀 — `/dashboard/campaigns` (운영 메뉴 "캠페인 풀")

## 3-2. 외부 채널 체험단 결과 등록 — 캠페인 상세 하단 "외부 채널 체험단 결과"

샤오홍슈처럼 **루비 밖에서 직접 섭외·방문시킨 체험단**의 결과를 캠페인에 붙여 결과 보고서로 냅니다(2026-09-11). 크리에이터가 루비 회원이 아니어도 됩니다.

1. 캠페인을 먼저 만듭니다(광고주 계정 또는 3-1 "대신 만들기"). 상태가 **모집중·마감·완료**여야 보고서가 열립니다.
2. 캠페인 상세 하단 **외부 채널 체험단 결과** 패널에서 엑셀(.xlsx/.csv)을 선택 → **미리보기** → 시트를 고르고 → **N행 등록**. 열 이름은 자동 인식됩니다: 순번 · 방문일자 · 계정링크 · 팔로워수 · 업로드 링크 · 좋아요/즐겨찾기 · 업로드 내용 (한/중/영 표기 모두 가능). 팀에서 쓰는 "체험단 결과" 양식 그대로 올리면 됩니다.
3. 같은 파일을 다시 올리면 순번 기준으로 갱신됩니다. "기존 결과를 지우고 교체"를 켜면 전체 교체. 행 오른쪽 휴지통으로 개별 삭제.
4. 결과 보고서: 성과 카드의 **리포트 공유** 버튼으로 링크(`/r/<토큰>`)를 만들어 클라이언트에게 보냅니다. 외부 결과만 있는 캠페인은 보고서 상단 지표가 **참여 크리에이터 · 게시 완료 · 팔로워 도달 · 좋아요**로 바뀌고, 표에 방문일·계정·팔로워·게시 여부·반응·게시 내용이 실립니다. 인쇄(PDF) 버튼으로 저장 가능. AI 요약도 외부 결과를 반영합니다(BUSINESS 플랜).

첫 적용: 명동 미쓰족발 건물 3개소(1층 미쓰족발 15명 · 2층 감자탕 8명 · 3층 K-BBQ 2명, 광고주 planderofficial 계정).

## 4. 크리에이터 강제 매칭(배정) — 캠페인 상세 하단 "운영자 강제 매칭"
응모가 없거나 특정 크리에이터를 직접 붙여야 할 때(대행사 운영 지원·파일럿 캠페인 등) 사용합니다.
1. 운영자로 캠페인 상세(`/dashboard/campaigns/[id]`) 진입 → 하단 **운영자 강제 매칭** 패널 (검수중·모집중·마감 캠페인에서만 활성)
2. 이름·이메일·소개로 **검색** → 체크박스로 여러 명 선택 (이미 `selected/completed`인 사람은 비활성 표시)
3. 배정 메모(선택, 응모 메시지로 기록) → **N명 배정**
4. 결과: 응모가 **선정(selected)** 상태로 생성(대기·미선정·취소 응모는 선정으로 전환), 크리에이터에게 "체험단에 배정되었어요", 광고주에게 "운영자가 N명을 배정했어요" 알림. 같은 사람 재배정은 자동 건너뜀

> 승인되지 않은 크리에이터, 운영자 외 계정의 호출은 DB에서 거부됩니다. 배정은 광고주에게 통보되므로 사전 협의 후 사용하세요.

## 6. 결제 내역 — `/dashboard/operator/payments`
- 토스페이먼츠 결제 기록(주문·금액·상태·플랜·광고주·결제키). **결제 CSV**(기간, 대표자·주소·세금계산서 이메일 포함)로 매출 대사
- **세금계산서**: 광고주가 결제 내역에서 "세금계산서 요청"을 누르면 운영자 알림 + 목록 상단 "요청 N건 대기". 홈택스(또는 향후 팝빌 API)에서 발행한 뒤 해당 결제의 **발행 완료 처리**(메모에 승인번호) → 광고주에게 "발행되었어요" 알림, 운영 기록에 남음. 카드 결제는 매출전표가 적격증빙이라 요청 건만 처리하면 됩니다
- 테스트 계정(agency·advertiser@luby.im 등)의 BUSINESS는 결제 없이 부여된 데모 구독
- 상태: **결제 완료**(구독 반영됨) · **대기중**(결제창만 열고 끝남 — 돈이 나가지 않음) · **입금 대기**(가상계좌 발급, 입금되면 자동으로 결제 완료·플랜 적용·광고주 알림) · **실패**(사유 칸에 토스 오류 코드)
- 같은 결제가 두 번 승인 요청되거나(새로고침·두 탭) 승인 응답이 끊겨도 토스 기록을 다시 조회해 맞추므로 구독이 두 번 늘어나거나 결제 완료가 실패로 바뀌지 않습니다. 사유가 `AMOUNT_MISMATCH` 인 실패는 승인 금액이 플랜 가격과 달라 플랜을 적용하지 않은 건 — 토스 상점관리자에서 확인 후 환불하세요
- **환불(총운영관리자 전용)**: 결제 완료 건의 **환불** → 사유(필수, 광고주에게는 안 보임) → '플랜도 바로 FREE로 전환(정기결제 해지)'(기본 켜짐, 끄면 플랜 유지) → 확인. 토스에서 **전액 취소**가 성공해야만 상태가 '취소(환불)'로 바뀌고, 운영 기록 '결제 환불'·광고주 알림('결제가 취소(환불)되었어요', 3~7영업일 안내)이 남습니다. 단건은 결제위젯 키, 정기결제는 자동결제 키로 취소합니다. 부분 환불·**가상계좌**(환불 계좌 필요)는 토스 상점관리자에서 하세요. 세금계산서를 이미 발행한 건이면 환불 후 홈택스에서 수정세금계산서(계약의 해제)를 발행하세요
- 토스 상점관리자에서 먼저 전액 취소한 건은(웹훅 등록 시) 자동으로 '취소(환불)'로 바뀌지만 **구독은 그대로**예요 — 필요하면 **플랜 강제 설정**으로 FREE 로 바꾸세요. 여기서 '환불'을 눌러도 토스가 '이미 취소됨'이라고 하면 기록만 맞춰요
- **매출전표**: 결제 완료·취소 건에 토스 매출전표(영수증) 링크가 있어요. 광고주도 구독·결제의 결제 내역에서 같은 링크를 봅니다

## 9. 계정·시스템 운영 (개발팀 협업 영역)
- **이메일**: 인증 메일 = Supabase SMTP(Resend, notify@luby.im, 브랜드 템플릿 5종) / 알림 메일 = 앱 → Resend. 반송·평판은 Resend 대시보드
- **소셜 로그인(Google·Kakao)**: Supabase Providers 설정 + Vercel `NEXT_PUBLIC_AUTH_PROVIDERS=google,kakao` 로 활성화 → 소셜 가입자는 온보딩에서 역할 확정
- **토스 라이브 전환**: Vercel `NEXT_PUBLIC_TOSS_CLIENT_KEY`/`TOSS_SECRET_KEY` 교체 → Redeploy → 소액 결제 실테스트
- **자동결제(빌링) 켜기**: 자동결제는 결제위젯 키가 아니라 **API 개별 연동 키**(자동결제 계약 MID)로 동작합니다. Vercel 에 `NEXT_PUBLIC_TOSS_BILLING_CLIENT_KEY`(test_ck_…/live_ck_…)·`TOSS_BILLING_SECRET_KEY`(test_sk_…/live_sk_…)를 넣고 Redeploy 하면 구독·결제에 '자동결제로 구독하기'가 나타납니다(키가 없으면 숨김 — 지금은 1개월 결제만). 라이브는 토스 자동결제 추가 계약 후 그 MID 의 키로
- **자동결제 운영**: 매일 10:00(KST) 갱신 작업이 ①응답을 못 받은 자동결제 주문 확인 ②유예(만료+3일)가 끝난 자동결제 해지 ③만료 24시간 안 구독 결제를 합니다. 결제 목록에 '자동결제' 배지, 상태 '결제 확인 중'은 토스 응답을 못 받아 다음 날 확인할 건입니다. 회원 상세 플랜 줄에 '자동결제 켜짐'·'결제 실패(유예 ○까지)'가 보입니다. 실패한 광고주에게는 매번 실패 알림이 가니, 연락이 필요하면 회원 상세에서 확인하세요
- **토스 웹훅 등록**(가상계좌 입금 자동 반영): 토스페이먼츠 개발자센터 → 웹훅 → URL `https://luby.im/api/payments/toss/webhook`, 이벤트 `PAYMENT_STATUS_CHANGED`·`DEPOSIT_CALLBACK`. 카드 결제만 쓴다면 없어도 동작합니다
- **공개 페이지**: 캠페인 `/c/[id]`, 크리에이터 `/p/[id]`(옵트인) — KR/EN/CN, 사이트맵 자동
- 테스트 계정·비밀번호는 별도 보관 파일 참조(채팅·문서에 기재 금지). 데모 계정은 회원 정보의 **데모 표시(is_demo)** 로 구분합니다(2026-10-22부터 테스트 계정 주소는 `@luby.im`, 이전 `@ruby-ai.kr`). `@luby.im` 에는 실제 운영 계정(admin@luby.im)도 있으므로 주소 도메인으로 데모를 판단하지 마세요. 데모 표시 계정은 공개 목록·통계·알림 메일·운영자 경고에서 빠지고, 이메일 수정도 막힙니다.
