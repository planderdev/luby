# Luby AI 운영자 매뉴얼

> 대상: 운영팀(admin@luby.im 등 operator 역할) · 최종 갱신 2026-08-19 · 운영자 메뉴는 `대시보드 → 운영` 하위

## 1. 아침 루틴
- 매일 09:30 **운영 다이제스트** 알림(승인 대기·검수 대기·정산 요청 합계) → 아래 순서로 처리
- 신규 크리에이터 가입·캠페인 검수 요청·출금 신청은 실시간 알림으로도 옵니다

## 2. 회원 관리 — `/dashboard/operator/users`
- 필터(전체/광고주/크리에이터/승인 대기), 검색, 사업자 정보(회사명·사업자번호·대행사 배지)·크리에이터 정보(지역·채널 수·팔로워·소개)
- **크리에이터 승인**: 채널 URL이 실제 프로필인지, 소개·분야가 채워졌는지 확인 후 승인 → 승인 알림·이메일 자동. 대기 목록은 **일괄 승인** 가능
- 광고주는 자동 승인. 문제가 있으면 승인 해제로 활동 중지

## 3. 캠페인 검수 — `/dashboard/operator/campaigns`
1. 행의 **AI 사전 점검** 클릭 → `이상 없음 / 수정 권장 / 승인 보류 권장` + 이슈(심각도·문제 문구·수정 제안)·요약
2. **상세보기**로 미션·제공 내역·포인트·일정 확인
3. **승인**(→ 모집중, 광고주 알림) 또는 **반려**(광고주에게 반려 알림; 사유는 AI 제안 문구를 채팅/메일로 전달)
- 체크 포인트: 경제적 대가 표기(#광고 #협찬) 미션 포함 여부 · 의료/효능 과장 · 확정적 수익 표현 · 개인정보 요구 · 미션 대비 포인트/제공 내역 균형 · 금지 업종

## 4. 정산 관리 — `/dashboard/operator/withdrawals`
- 출금 신청(요청 시 이미 포인트 차감됨) → 계좌 확인 후 **지급 완료** / **반려**(사유 입력 → 포인트 자동 환불)
- 회계 대사: **정산 CSV**(기간 선택) 다운로드 → 은행 이체 후 지급 처리
- 최소 출금 10,000P. 추천 보상(500P)·콘텐츠 승인 적립은 크리에이터 포인트 내역에서 추적 가능

## 5. 결제 내역 — `/dashboard/operator/payments`
- 토스 결제 기록(상태·금액·플랜·광고주). **결제 CSV**(기간)로 매출 대사. 라이브 키 전환 후에는 토스 콘솔과 교차 확인

## 6. 통계 — `/dashboard/operator/stats`
- KPI(회원·캠페인·응모·주간 신규), 상태 분포, 재무 카드(추천 유입 누계·누적 매출·포인트 지급·정산 대기), **8주 추이**(신규 가입 / 캠페인 승인·응모 / 콘텐츠 승인·포인트 / 결제 / 추천 유입)

## 7. 계정·시스템 운영 (참고)
- 이메일: Supabase 인증 메일은 Resend SMTP(notify@luby.im, 템플릿 5종), 알림 메일은 `/api/notifications/email` → Resend. Resend 대시보드에서 반송/평판 확인
- 자동화(pg_cron): 매시 캠페인 자동 마감 · 매일 구독 만료 안내 · 09:30 리마인더 8규칙. 대상 미리보기 SQL: `select * from send_lifecycle_reminders(true)`
- 소셜 로그인 활성화: Supabase Providers(Google/Kakao) 설정 후 Vercel `NEXT_PUBLIC_AUTH_PROVIDERS=google,kakao`
- 토스 라이브 전환: Vercel `NEXT_PUBLIC_TOSS_CLIENT_KEY`/`TOSS_SECRET_KEY` 교체 → Redeploy → 소액 결제 실테스트
- 테스트 계정·비밀번호는 별도 보관 파일 참조(채팅·문서에 기재하지 않음)
