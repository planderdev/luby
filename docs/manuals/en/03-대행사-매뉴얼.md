# Luby AI Marketing Agency Manual

> Target audience: Agencies operating experience-group campaigns on behalf of multiple clients · Last updated 최종 갱신 2026-08-19 · All features in the [Advertiser Manual](01-광고주-매뉴얼.md) work the same way

## 1. Signing Up as an Agency
- During signup, select **Marketing Agency** under advertiser type → the company name field changes to **Agency Name**. Enter the agency's own business registration number
- If you already signed up as a brand, you can change this under `Settings → Advertiser Type`. An "Agency" badge will appear on your profile/operator screen

## 2. Running Campaigns per Client
- Enter the campaign's **business name (business_name) separately for each campaign** → manage Client A/B/C campaigns from a single account and dashboard
- **Duplicate**: Detail page → "Create new campaign from this one" → channels, missions, rewards, and schedule are pre-filled → just change the client's business name and recruitment period, then submit for review
- Just enter a single line about the client's business (location, customers, key product, target country) into **Let AI Handle Everything** to get a draft

## 3. Sourcing Creators
- `Find Creators`: filter by industry, region, channel, followers, sorting + quick filters **Xiaohongshu / Douyin / Lemon8 / Has Public Profile**
- When sharing candidates with a client, use the **public profile link** on the creator's detail page (opt-in creators only)
- BUSINESS: AI matching (fit score & reasoning) → invite, then chat once selected

## 4. Risk Management and Reporting
- When a review is requested, the operator can reference **AI pre-screening** (missing ad disclosure, exaggerated claims, unreasonable requests) to approve/reject — adding `#AD #Sponsored` tags to missions in advance reduces rejections
- Client reporting: campaign performance cards (funnel, reach by channel), **performance report notifications** upon completion, performance chips in the campaign list, public campaign page links (KR/EN/CN)

## 5. Plans
- To run multiple clients simultaneously, you'll need at least the **BUSINESS** plan (unlimited campaigns, full AI package, unlimited applicants, chat). For large-scale operations, API access, or a dedicated manager, contact ENTERPRISE sales (contact@plander.io)
