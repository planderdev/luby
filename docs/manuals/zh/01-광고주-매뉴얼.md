# Luby AI 广告主手册（品牌·个体商户）

> 对象：开设活动招募创作者的广告主 · 最终更新 2026-08-19 · https://luby.im
> 代理商·执行商请同时参考本手册与 [03-代理商-手册](03-代理商-手册.md)。

## 1. 开始使用

### 1-1. 注册
1. 在 https://luby.im/signup 选择**广告主**（或社交登录后在引导流程中选择角色）
2. **广告主类型**：在 `品牌·个体商户` / `营销代理商·执行商` 中选择
3. 输入公司·商号名称、营业执照号（10位数字）、负责人姓名·联系方式 → 注册
4. 在收件箱中点击**邮箱验证**链接 → 进入仪表盘（广告主可立即使用，无需等待审核）

> 注册完成后会立即收到**欢迎通知**，并附有"创建第一个活动"的链接。FREE 套餐可免费创建 1 个活动。

### 1-2. 填写公司资料 — `仪表盘 → 设置`
- 负责人姓名 · 头像照片（Logo） · **广告主类型** · 公司名称 · 主营行业 · 公司简介 · 网站
- **发票·结算信息**（法人代表姓名·营业场所地址·发票接收邮箱）— 用于 BUSINESS 付费时开具发票。未填写时将发送至负责人邮箱
- 只需按照设置页顶部**公司资料完成度**进度条上的"下一步：○○"按钮操作即可。创作者在应征前会查看广告主主页（`/dashboard/advertisers/[id]`）来判断可信度。

### 1-3. 仪表盘首页解读
- 顶部卡片：已注册活动数·招募中·当前套餐。下方**今日待办**会显示待选定的应征者、待审核内容、未读消息、临近截止、订阅到期、草稿等条数。
- **近30天转化漏斗**（只要有一个公开活动即会显示）：展示公开页面访问（独立访客·浏览量）→ 应征 → 选定 → 内容发布各阶段的转化率，并附有流量来源（二维码海报·分享链接·目录·推荐·直接访问）以及浏览量最高的活动链接。各活动详细数据可在活动详情 → 活动成效中查看。

## 2. 创建活动 — `仪表盘 → 活动 → 新建活动`

### 2-1. 交给 AI 全权处理（推荐，约需 20~40 秒）
1. 在 STEP 1 中输入**商号名称**与**一句话行业说明**（例："位于明洞的K美妆精品店，中国·台湾游客占比60%"）
2. 点击**交给 AI 全权处理** → 进度面板（显示用时·阶段）→ 标题、宣传类型、分类、渠道、各渠道任务、关键词、招募人数、提供内容、积分将自动填充
3. STEP 3 的**招募期间（开始·结束）**需由广告主自行填写（AI 不会随意设定）。体验期间·星期/时间·当日预约·常态招募选项也在此设置
4. 逐步检查并修改各步骤 → 在 STEP 5 点击**申请审核**（或**保存草稿**）

> 若在渠道中加入**小红书·抖音·Lemon8**，AI 会按照当地语言格式（笔记·话题标签·中韩双语关键词）撰写任务内容。若面向中国·华人圈游客的商铺·K美妆·K美食，推荐使用小红书。

### 2-2. 手动创建
- 5步构建流程：**基本信息 → 宣传·渠道·任务 → 体验日程 → 招募设置·关键词 → 提供内容·积分**。每个步骤都可点击"AI 推荐"按钮，仅针对该字段获取建议。
- 若必填项为空，保存时会弹出提示，引导至相应步骤。
- **对比基准**：在第4步招募人数下方，会显示同类行业（样本不足3个时为全平台）近180天活动的招募人数中位数·平均竞争比·完成率·常用渠道；在第5步积分下方，会显示积分中位数与常见区间（25~75%）·通过率。若输入值超出该区间，会附上简短提示，例如"低于平均水平——如果应征较少，可考虑提高积分"。AI 推荐（全权处理·人数·积分）也基于同样的对比基准，在合理区间内提出建议（竞争较低的行业倾向将积分设在区间上限）。仅显示汇总数据，不会暴露其他广告主的具体活动信息。

### 2-3. 审核 → 开始招募
- 提交审核后，运营人员将进行确认（通常当天完成）。**通过审核后会收到通知·邮件**，活动状态变为`招募中`
- **驳回（要求修改）**时：会通过通知·邮件收到运营团队的修改要求，活动详情页顶部的红色横幅也会显示相同内容 → 点击**"修改后重新申请审核"** → 修改要求会固定显示在构建页顶部，保存后将自动提交重新审核申请（第N次）
- 状态：`草稿 → 审核中 → 招募中 → 截止 → 完成` / `驳回（需修改）` / `已取消`
- **成效报告分享**（代理商 → 向客户汇报）：在活动详情"活动成效"板块中点击**分享报告** → 生成分享链接 → 将 `luby.im/r/…` 链接发送给客户·团队。无需登录即可打开，每次打开都会生成最新数据（招募进度·竞争比·预计触达·发布内容·转化漏斗·各渠道触达·内容链接）。不包含创作者联系方式·结算信息，可通过"保存为 PDF"按钮打印/导出。点击关闭分享后链接立即失效。BUSINESS 套餐在**活动完成后会自动生成一次 AI 摘要**，在同一面板中点击**AI 摘要 → 生成/重新生成摘要**，系统会基于汇总数据撰写结果概述、解读及后续建议，并显示在报告顶部与成效板块中（数据变化时可"重新生成"）
- **调整招募中的活动**：在活动详情的"延长招募·增加人数"面板中，仅可进行**延长招募截止时间**和**增加招募人数**（为保护应征者权益，缩短、减员、修改内容均被锁定）。若需修改内容，请取消后复制该活动重新提交审核

### 2-4. 修改·复制·取消
- **修改**（草稿·审核中·驳回状态）：点击详情页顶部**修改**按钮 → 打开构建页面并自动填入原有信息 → 保存（草稿）或**申请审核**。被驳回的活动可点击**"修改后重新申请"**按钮修改同一活动并重新提交。招募开始后请使用复制功能代替修改
- **以此活动新建**（详情页顶部）：预填渠道·任务·关键词·提供内容·日程，仅需重新指定招募期间
- **取消活动**（审核中·招募中·截止状态）：会向应征者发送取消通知，待处理的应征将自动取消。若已有应征者获得积分发放，则无法取消（保持截止状态）。已有应征者的活动无法删除。

## 3. 扩大招募

### 3-1. 分享链接（无需登录即可浏览的公开页面）

![通过分享链接打开的公开活动页面（luby.im/c/…）——无需登录即可浏览，可引导注册·应征](/docs-img/campaign.jpg)
- 点击详情页顶部**分享链接 ▾** → 选择韩语（KR）/ English（EN）/ 中文（CN）后复制 → 粘贴至 Instagram·KakaoTalk·小红书·官网
- 公开页面（`luby.im/c/…`）中包含任务·提供内容·积分·日程及**"注册并应征"**按钮，可让新创作者直接转化为应征。
- **门店二维码海报**：在同一弹出面板中点击**打印门店二维码海报（A4）** → 生成包含活动标题·商户名称·福利·积分·招募人数·截止日期·渠道及公开页面二维码的 A4 竖版海报。可通过 `?lang=en`/`zh` 生成英文·中文版本。点击**打印 / 保存为PDF**即可直接输出，张贴于收银台·入口·桌面，来店顾客扫码即可应征（仅活动所有者·运营人员可打开）。
- **流量来源统计**：通过分享链接·二维码海报·活动目录·创作者推荐链接进入的公开页面浏览会自动统计。在活动详情**活动成效 → 转化漏斗**最上方会显示"公开页面访问"（独立访客数）与访问→应征转化率，下方显示各流量来源浏览量，同时也会反映在分享报告与AI摘要中。不保存个人信息（访客仅通过每日变化的哈希值区分），自己查看自己活动产生的浏览不计入统计。

### 3-2. AI 创作者匹配·邀请（BUSINESS）
- 点击详情页下方**AI 匹配** → 显示带匹配度分数与推荐理由的候选人 → 点击**邀请**。创作者接受后将自动完成应征。

### 3-3. 创作者搜索 — `仪表盘 → 寻找创作者`
- 搜索关键词（姓名·简介） · 行业 · 地区 · 渠道 · 粉丝数 · 排序（粉丝数/完成数/最新）
- **快速筛选**：`小红书` `抖音` `Lemon8` `有公开主页`
- 点击卡片 → 查看作品集（渠道·完成记录） → **邀请**（选择招募中的活动）

## 4. 应征者选定 → 体验 → 内容审核 — 活动详情

1. **应征者列表**：查看渠道·粉丝数·应征留言 → `选定` / `未选定`。FREE 套餐最多可查看10位应征者
2. 选定后会通知创作者。可通过**聊天**（BUSINESS）协调日程·须知（`仪表盘 → 消息`）
3. 创作者提交内容链接后会收到通知。在应征者行中使用**AI 预审**，先确认渠道匹配度与任务检查点
4. **通过** → 立即向创作者发放积分（原子化处理） · **要求修改** → 传达反馈 → 重新提交 → 再次审核
5. 全部选定人员通过审核后（截止后），活动将**自动完成**，并收到**成效报告通知**（应征数·选定数·通过数·发放积分·预计触达）

> 若审核积压超过3天，将收到提醒通知；若截止后超过3天仍未完成选定，将收到"有N位应征者正在等待选定"的通知。

## 5. 查看成效
- 活动详情**活动成效**卡片：招募进度·应征竞争比·预计触达（已选创作者粉丝数总和）·已发放积分·转化漏斗·各渠道触达情况
- 活动列表卡片标签：`待选定 N` `应征 N` `已选定 N/招募人数` `已通过 N · 已发放 P`

## 6. 订阅与付费 — `仪表盘 → 订阅·付费`
- FREE：首个活动免费1次 · 可查看10位应征者 / BUSINESS：活动数量不限 · AI匹配·邀请·聊天 · 应征者数量不限 / ENTERPRISE：请咨询
- 通过 Toss Payments 支付窗口结算（信用卡）。30天订阅周期，到期前7天提醒通知，到期后自动转为FREE
- 在订阅·付费页面下方**付费记录**中可查看逐笔明细。信用卡支付以刷卡小票作为合规凭证，如需发票请点击**"申请开具发票"** → 运营团队将依据设置中的发票信息开具后通知

## 7. 通知·邮件设置 — `设置 → 邮件通知`
- 站内通知始终接收。邮件通知可分别开关**进度通知 / 提醒·推荐**两类。所有通知邮件底部均附有退订链接。

## 8. 常见问题
- **活动一直处于审核中，没有进展**→ 属于运营人员待审核状态。如未收到驳回通知，将很快处理完成。
- **看不到应征者（限10位以内）**→ 属于FREE套餐限制。请升级至BUSINESS套餐。
- **AI 草稿不满意** → 再次点击可生成新草稿。行业说明写得越具体（位置·顾客·主打商品·目标国家），效果越好。
- **招募期间已过但仍在继续接受应征** → 若开启了`常态招募`，则不会自动截止。请在STEP 3中关闭该选项，或使用取消/截止活动功能。

### 每周成效摘要
每周**周一上午9点**，我们会通过一条通知·邮件为您汇总上周活动成效（新增应征·选定·内容提交·通过数、本周截止、待审核、已完成活动）。可在设置 > 邮件接收设置的**摘要推送**中关闭该功能。

### 应征者 AI 匹配度评估（BUSINESS）
在活动详情 > 应征者列表右侧点击**AI 匹配度评估**按钮，系统会将待处理应征者（每次最多30人）与活动条件（要求渠道·领域·地区·报酬与粉丝比·应征留言·体验记录）进行对比，给出0~100分及评分依据、选定前需确认的事项（如是否可海外配送等），并按分数排序。有新应征进入时按钮会再次出现，可点击"重新评估"进行整体重评。评估完成后可使用**选定前N名**按钮按分数顺序批量选定（默认值：剩余招募人数），最终决定权仍由广告主掌握。

### AI 使用额度
AI 功能（活动撰写·匹配·应征者匹配度·内容审核·应征草稿·报告摘要）按账户设有**月度额度**——FREE 30次，BUSINESS 300次，ENTERPRISE 不限。每月1日重置，可在付费·套餐页面查看本月使用量。达到上限后会显示提示，AI功能将锁定至下月（手动功能不受影响）。

### 推送通知
在设置 > **推送通知 > 在此设备上开启**中开启后，即使关闭应用，应征·选定·审核通知也会直接推送到设备（邮件接收设置中的分类同样适用于推送）。Android·PC Chrome可直接开启，**iPhone需通过Safari分享 → 添加到主屏幕安装的Luby AI应用中**开启。可按设备分别开关。

### 活动复制 + 结合过往成效（AI）
在活动详情 > 复制新建活动时，第1步会出现**"结合过往成效重新提议"**按钮。系统会依据原活动的应征竞争比·通过率·各渠道触达情况，调整招募人数·积分·渠道·任务后生成草稿，并以2~4行说明修改内容及原因（例如："竞争比降至0.4:1，因此将积分从15,000提升至20,000P"）。此功能计入AI月度额度。若活动**完成7天后**仍未创建新活动，将收到一次"是否需要结合过往成效，为您推荐下一个活动？"的通知，点击链接可直接进入该界面（可在提醒·推荐类别中关闭）。
