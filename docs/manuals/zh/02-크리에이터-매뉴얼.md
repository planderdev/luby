# Luby AI 创作者手册

> 适用对象：报名参与活动、完成体验并发布内容后获得积分的创作者 · 最终更新 2026-08-19 · https://luby.im

> 注册前说明页面：**luby.im/creators**（EN: /en/creators，CN: /zh/creators）— 无需登录即可查看当前招募中的活动数量、剩余名额及积分水平和进行方式。分享给朋友时请使用此链接。

## 1. 注册与审核

> **语言**：注册、登录、密码相关页面支持韩语、English、中文。点击画面右上角的 **KR / EN / CN** 切换语言后会记住选择，从英文、中文活动页面进入时会直接以该语言打开。登录后，首页（概览·今日待办·推荐活动）、菜单、活动浏览（列表·筛选）、活动详情、报名、我的报名（内容提交）均以同一语言显示，英文、中文用户看到的活动标题·内容也会是翻译版本。设置（频道·专业领域·公开资料·通知）、收到的邀请、积分·提现、消息、作品集等创作者端全部页面均以同一语言显示。通知邮件目前仍以韩语发送。
1. 在 https://luby.im/signup 中选择**创作者**（或使用 Google/Kakao 继续 → 在引导流程中选择创作者）
2. 输入姓名·昵称、活动地区、主要频道（URL）、专业领域（最多3个）→ 注册 → **邮箱验证**
3. 运营人员审核频道·资料后进行**批准**（通常在24小时内完成）。收到批准通知·邮件后即可报名活动。批准前也可浏览活动。

## 2. 完善个人资料 — `控制面板 → 设置`
请将概览首页和设置页面顶部的**资料完成度**指标提升至100%。完成度越高，推荐与邀请就越多。

| 项目 | 位置 | 提示 |
|---|---|---|
| SNS频道（30%） | 设置 → 频道（`#channels`） | 选择频道类型后，URL·账号示例会随之变化。**小红书**以App资料中的 `小红书号` 作为账号，URL为个人主页分享链接（可使用 xhslink 短链接）· 抖音为 `抖音号` · Lemon8为 `lemon8-app.com/@…`。与所选频道类型不符的地址将无法保存 |
| 专业领域（25%） | 设置 → 专业领域（`#categories`） | 最多3个。与我的领域相符的活动会优先推荐 |
| 粉丝数（15%） | 按频道分别输入 | 用于广告主筛选及预计触达计算 |
| 一句话简介（15%） | 设置 | 广告主在挑选创作者时最先阅读的一句话（10字以上） |
| 活动地区（10%）· 头像照片（5%） | 设置 | 基于地区的推荐 · 带照片的资料选中率更高 |

## 3. 查找活动 — `控制面板 → 活动`

![活动目录 — 频道·排序筛选与剩余名额徽章](/docs-img/directory.jpg)
- 默认按**推荐顺序**排序（结合我的领域·地区·是否已报名），显示 `剩余N个名额`（报名人数少于招募人数、入选概率较高的活动）、`我的领域`、`我的地区`、`已报名` 徽章 / 可按最新发布、临近截止、积分高低排序，支持按行业、地区筛选
- 无需登录即可浏览的公开活动目录（luby.im/c，含EN·CN版本）同样支持**按临近截止·最新发布·积分高低**排序及频道·地区筛选
- 概览首页展示**"适合我的活动"**3个 · 本周新增活动数 · **当我所在领域的活动将在48小时内截止**时会收到早间提醒
- **新活动即时提醒**：当符合我的专业领域（或我的活动地区 + 我拥有的频道）的活动开始招募时，会立即收到通知·推送·邮件（每日最多1条，其余会汇总至周一的摘要中）。填写的专业领域·地区·频道越完整，推送就越精准，可在 `设置 → 邮件通知` 的**提醒·推荐**中关闭该功能。
- 活动详情：按频道列出任务内容·提供事项·招募期限·积分·广告主主页链接
- 活动详情页右侧的**入选可能性**卡片：会展示竞争比例（报名数/招募数·距截止天数）、与我的领域·地区·频道的匹配情况、完成历史，并给出高/中/低等级及改进建议（注册频道、添加领域、报名留言）。该结果仅供参考，最终入选由广告主决定

## 4. 报名 · 邀请

![公开活动页面 — 积分·招募截止时间·注册并报名](/docs-img/campaign.jpg)
1. 在详情页点击**报名** → 填写报名留言（可选）。点击 **AI生成初稿**按钮，系统会根据活动任务和我的资料自动生成2~3句内容（可编辑）。若竞争激烈，可用具体的策划方案来突出差异化，并以我实际拥有的频道为中心撰写，切勿虚构未注册的频道或不存在的经历。在Luby AI中完成的体验次数可作为信任依据写入留言
2. 在报名等待状态下可**取消报名**。同一活动不可重复报名
3. 若广告主发出邀请，可在 `控制面板 → 收到的邀请` 中**接受（自动报名）** / 拒绝
4. 入选后会收到通知·邮件 → 可通过与广告主的**聊天**（`控制面板 → 消息`）协调日程

## 5. 体验 → 内容提交 → 审核 — `控制面板 → 我的报名`
1. 按照已入选活动的任务要求发布内容（**必须标注#广告 #赞助等经济利益关系**）
2. **内容提交**：发布链接 + 备注 → 由广告主审核
3. **通过** → 积分立即发放 / **要求修改** → 查看反馈 → 在同一页面进行**重新提交**
4. 体验结束后若未提交内容，将收到提醒

## 6. 积分与提现 — `控制面板 → 积分`
- **持有积分**（1P = 1韩元）· **积分明细**：按时间顺序显示内容通过（+活动名称）· 推荐奖励 · 提现 · 提现中 · 被驳回 等记录
- **申请提现**：最低10,000P，填写银行·账户·开户人信息 → 申请后立即扣除积分 → 经运营人员确认后发放（若被驳回则自动退还并显示原因）

## 7. 公开资料 · 好友推荐
- 打开 `设置 → 公开资料` 开关 → 生成 `luby.im/p/我的ID` 链接（KR/EN/CN）— 仅展示姓名·照片·简介·地区·领域·频道·完成的合作记录（邮箱·联系方式·结算信息不公开）。可将该链接作为作品集发送给广告主·海外品牌
- 在 `控制面板 → 我的作品集` 中可保存为PDF，**打印QR名片A4页** → 一张A4纸可打印10张名片规格（90×55mm）的内容，扫描QR码即可打开我的公开资料（需开启公开资料功能）。可在到店拜访·活动·快闪店时直接递交给店主
- 开启公开资料后，**我的作品集**顶部会显示资料访问量（总访问·独立访客·近7天）及访问来源（QR名片 / 作品集链接 / 直接访问·搜索）。访客仅通过每日变化的哈希值进行区分，不保存个人信息，且不计入本人查看的记录
- 在首页**邀请好友得500P**卡片中复制·分享我的推荐链接（luby.im/creators?ref=…），可查看注册情况、奖励及本月次数。在活动详情页点击**分享给好友** → 复制该活动专属的推荐链接（?ref）。通过链接注册的好友**完成首次体验后可获得500P**（每月最多5人）。可在概览首页的"我的推荐注册"中查看

## 8. 通知·像App一样使用
- 应用内通知 + 邮件（进度通知 / 提醒·推荐 可分别开关，位于 `设置 → 邮件通知`）
- 在移动端浏览器中打开 luby.im → 点击**添加到主屏幕** → 即可像App一样启动（快捷入口：活动·我的报名·通知）

## 9. 常见问题
- **一直未通过审核** → 请确认频道URL是否为真实主页，简介·领域是否已填写完整。若等待超过24小时，请联系 contact@plander.io
- **看不到报名按钮** → 可能是尚未通过审核，或该活动已结束招募
- **积分没有到账** → 积分会在广告主通过审核后发放。请在"我的报名"中查看状态（已提交/要求修改/已通过）

### 每周摘要
每周**一上午9点**，您会收到一条汇总通知·邮件，内容包括：我所在领域·地区新开放的活动、本周截止的活动、待报名·待提交·待审核的数量、上周通过及获得的积分、（若已开启公开资料）上周我的资料访问量及QR名片访问来源，以及是否可提现。可在"设置 > 邮件接收设置"的**摘要**选项中关闭此功能。

### 推送通知
在"设置 > **推送通知 > 在此设备上开启**"中点击开启后，即使关闭App，入选·通过·截止等通知也会直接推送到设备（邮件接收设置中的分类同样适用于推送）。Android·PC版Chrome可直接开启，**iPhone需通过Safari分享 → 添加到主屏幕安装Luby AI应用后**再开启。可按设备分别开启或关闭。

### 我的作品集（PDF）
在菜单 > **我的作品集**中，可以以适合展示给品牌方的形式查看我的资料·频道·领域·合作记录，并可**保存为PDF·打印**。即使公开资料功能处于关闭状态，本人仍可查看；若开启该功能，则可通过链接（`luby.im/p/…`）分享同一页面内容。
