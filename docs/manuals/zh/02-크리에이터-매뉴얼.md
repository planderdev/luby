# Luby AI 创作者手册

> 适用对象：报名参与活动、完成体验并发布内容以获取积分的创作者 · 最终更新 2026-08-19 · https://luby.im

> 注册前须知页面：**luby.im/creators**（EN: /en/creators，CN: /zh/creators）— 无需登录即可查看当前招募中的活动数量、剩余名额和积分水平及进行方式。分享给朋友时可使用此链接。

## 1. 注册与审核
1. 在 https://luby.im/signup 中选择 **创作者**（或通过 Google/Kakao 继续 → 在引导流程中选择创作者）
2. 输入姓名/昵称、活动地区、代表渠道（URL）、专业领域（最多3个）→ 注册 → **邮箱验证**
3. 运营方审核渠道及资料后进行**批准**（通常在24小时内完成）。收到批准通知或邮件后即可报名。批准前也可以浏览活动。

## 2. 完善资料 — `控制台 → 设置`
请将概览首页及设置页顶部的 **资料完成度** 进度条填满至100%。完成度越高，被推荐和邀请的机会越多。

| 项目 | 位置 | 提示 |
|---|---|---|
| SNS渠道（30%） | 设置 → 渠道（`#channels`） | 选择渠道类型后，URL、账号示例会随之变化。**小红书**的账号为个人主页中的 `小红书号`，URL 可使用主页分享链接（支持 xhslink 短链）；抖音为 `抖音号`；Lemon8 为 `lemon8-app.com/@…`。与所选渠道类型不符的地址将无法保存 |
| 专业领域（25%） | 设置 → 专业领域（`#categories`） | 最多可选3个。与我的领域相关的活动会被优先推荐 |
| 粉丝数（15%） | 按渠道分别输入 | 用于广告主筛选及预估触达计算 |
| 一句话简介（15%） | 设置 | 是广告主在挑选创作者时最先阅读的内容（需10字以上） |
| 活动地区（10%）· 头像（5%） | 设置 | 用于基于地区的推荐 · 有头像的资料入选率更高 |

## 3. 查找活动 — `控制台 → 活动`
- 默认按**推荐排序**（综合我的领域、地区、是否已报名等因素），显示 `仅剩N个名额`（报名人数少于招募人数、入选概率更高的活动）、`我的领域`、`我的地区`、`已报名` 标签 / 可切换为最新排序、截止日期临近排序、积分排序，并支持行业、地区筛选
- 无需登录即可浏览的公开目录（luby.im/c，包含EN、CN版本）同样支持 **截止日期临近排序、最新排序、积分排序**，并提供渠道、地区筛选
- 概览首页展示**"为我推荐的活动"**3个 · 本周新增活动数 · 当**我的领域活动将在48小时内截止**时会发送早间提醒
- **新活动即时提醒**：当符合我的专业领域（或我的活动地区+我拥有的渠道）的活动开始招募时，会立即收到通知、推送及邮件（每日最多1次，其余汇总在周一摘要中发送）。填写的专业领域、地区、渠道信息越完整，提醒越精准，可在 `设置 → 邮件通知` 的**提醒与推荐**中关闭该功能。
- 活动详情页：任务内容（按渠道区分）·提供内容·招募期间·积分·广告主资料链接
- 活动详情页右侧的**入选可能性**卡片：显示竞争比例（报名人数/招募人数及倒计时天数）、与我的领域/地区/渠道的匹配度、以往完成记录，并给出高/中/低等级评价及改善建议（如注册渠道、补充领域、优化报名留言）。此为参考性预估，最终入选与否由广告主决定

## 4. 报名 · 邀请
1. 在详情页点击**报名**→ 填写报名留言（可选）。点击 **AI草稿**按钮，可根据活动任务与我的资料自动生成2~3句内容（可修改）。竞争激烈时应通过具体的策划方案脱颖而出，内容应围绕自己实际拥有的渠道撰写，切勿虚构未注册的渠道或不存在的经历。可将在 Luby AI 完成的体验次数作为可信度佐证
2. 报名待审核期间可**取消报名**。同一活动不可重复报名
3. 若被广告主邀请，可在 `控制台 → 收到的邀请` 中选择**接受（自动报名）**或**拒绝**
4. 入选后会收到通知及邮件 → 可在**消息**（`控制台 → 消息`）中与广告主沟通协调日程

## 5. 体验 → 内容提交 → 审核 — `控制台 → 我的报名`
1. 按被选中活动的任务要求发布内容（**必须标注 #广告 #赞助 等经济利益关系**）
2. **提交内容**：填写发布链接及备注 → 提交给广告主审核
3. **审核通过** → 积分立即到账 / **要求修改** → 查看反馈 → 在同一页面**重新提交**
4. 若体验期结束仍未提交，会收到提醒通知

## 6. 积分与提现 — `控制台 → 积分`
- **当前积分**（1P = 1韩元）· **积分明细**：按时间顺序显示内容审核通过（+活动名称）· 推荐奖励 · 提现 · 提现处理中 · 被拒绝 等记录
- **申请提现**：最低10,000P，需填写银行、账号、账户持有人信息 → 申请后立即扣除相应积分 → 经运营方确认后打款（如被拒绝将自动退回积分并显示原因）

## 7. 公开资料 · 好友推荐
- 打开 `设置 → 公开资料` 开关 → 生成链接 `luby.im/p/我的ID`（提供KR/EN/CN版本）— 仅展示姓名、照片、简介、地区、领域、渠道、完成的合作项目（邮箱、联系方式、结算信息不公开）。可用作作品集发送给广告主或海外品牌
- 在 `控制台 → 我的作品集` 中可保存为PDF，或**打印A4尺寸的二维码名片** → 一张纸可打印10张名片规格（90×55mm），扫描二维码即可打开我的公开资料（需先开启公开资料）。适合在门店拜访、活动、快闪现场直接递给对方
- 开启公开资料后，**我的作品集**页面顶部会显示资料浏览量（总浏览量、独立访客数、近7天数据）及来源渠道（二维码名片/作品集链接/直接访问·搜索）。访客仅通过每日变化的哈希值区分，不保存个人信息，且不计入本人查看记录
- 在首页**邀请好友得500P**卡片中，可复制并分享我的推荐链接（luby.im/creators?ref=…），查看注册情况、奖励及本月次数。在活动详情页点击**分享给好友**可复制该活动专属推荐链接（?ref）。通过该链接注册的好友**完成首次体验后可获得500P**（每月最多5人）。可在概览首页"我的推荐注册"中查看相关情况

## 8. 通知与像App一样使用
- 应用内通知 + 邮件通知（进度通知/提醒与推荐可分别开关，位于 `设置 → 邮件通知`）
- 在手机浏览器中打开 luby.im → 点击**添加到主屏幕** → 即可像App一样启动（快捷入口：活动、我的报名、通知）

## 9. 常见问题
- **审核一直未通过** → 请确认渠道URL是否为真实资料页面，以及简介、领域是否已填写完整。若等待超过24小时，请联系 contact@plander.io
- **看不到报名按钮** → 可能是尚未通过审核，或该活动已截止招募
- **积分没有到账** → 需经广告主审核通过后才会发放积分。请在"我的报名"中查看状态（已提交/要求修改/已通过）

### 每周摘要
每周**周一上午9点**，您将通过一条通知/邮件收到以下内容：符合我的领域、地区的新开放活动，本周截止的活动，待报名·待提交·待审核的数量,上周通过审核并到账的积分，（若开启公开资料）上周资料浏览量及二维码名片带来的访问情况，以及是否可申请提现。可在设置>邮件接收设置的**摘要**中关闭该功能。

### 推送通知
在设置 > **推送通知 > 在此设备开启**后，即便应用处于关闭状态，入选、审核通过、截止提醒等通知也会直接推送到设备（邮件接收设置中的分类同样适用于推送）。Android及PC Chrome可直接开启，**iPhone用户需通过Safari的分享→添加到主屏幕安装Luby AI应用后**才能开启。可按设备分别开启或关闭。

### 我的作品集（PDF）
在菜单 > **我的作品集**中，可以以作品集形式展示您的资料、渠道、领域及合作履历，供品牌方查阅，并支持**保存为PDF·打印**。即使关闭公开资料，本人仍可查看；若开启，则可通过链接（`luby.im/p/…`）分享同一页面。
