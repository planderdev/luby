# Luby AI 创作者手册

> 适用对象：报名参加活动、完成体验并发布内容后领取积分的创作者 · 最终更新 2026-08-19 · https://luby.im

> 加入前介绍页面：**luby.im/creators**（EN: /en/creators, CN: /zh/creators）— 无需登录即可查看当前招募中的活动数量、剩余名额及积分水平和进行方式。想推荐给朋友时，使用这个链接。

## 1. 注册与审核

> **语言**：注册、登录、密码相关页面支持韩语、English、中文。点击屏幕右上角的 **KR / EN / CN** 切换语言后会记住选择，若从英文、中文活动页面进入，则会直接以该语言打开。登录后，首页（概览、今日待办、推荐活动）、菜单、活动浏览（列表、筛选）、活动详情、报名、我的报名（内容提交）等页面也会以相同语言显示，英文、中文用户还可看到活动标题和内容的翻译版本。其余页面（设置、消息、积分等）目前仍为韩语。
1. 在 https://luby.im/signup 选择 **创作者**（或通过 Google/Kakao 继续 → 在引导流程中选择创作者）
2. 输入姓名/昵称、活动地区、代表频道（URL）、专业领域（最多 3 个）→ 注册 → **邮箱验证**
3. 运营人员会审核频道与资料后予以 **批准**（通常在 24 小时内完成）。收到批准通知或邮件后即可报名。批准前也可以浏览活动。

## 2. 完善个人资料 — `控制台 → 设置`
请将概览首页和设置页顶部的 **资料完整度** 仪表盘填满至 100%。完整度越高，获得推荐和邀请的机会就越多。

| 项目 | 位置 | 提示 |
|---|---|---|
| SNS 频道 (30%) | 设置 → 频道 (`#channels`) | 选择频道类型后会显示相应的 URL/账号示例。**小红书**的账号为应用资料中的 `小红书号`，URL 为资料分享链接（支持 xhslink 短链接）· Douyin 为 `抖音号` · Lemon8 为 `lemon8-app.com/@…`。与所选频道类型不符的地址将无法保存 |
| 专业领域 (25%) | 设置 → 专业领域 (`#categories`) | 最多可选 3 个。系统会优先推荐符合我的领域的活动 |
| 粉丝数 (15%) | 按频道分别输入 | 用于广告主筛选及预估触达计算 |
| 一句话简介 (15%) | 设置 | 这是广告主在挑选时最先阅读的一句话（需 10 字以上） |
| 活动地区 (10%) · 头像 (5%) | 设置 | 用于基于地区的推荐 · 带头像的资料被选中概率更高 |

## 3. 查找活动 — `控制台 → 活动`

![活动目录 — 频道/排序筛选及名额剩余徽标](/docs-img/directory.jpg)
- 默认排序为 **推荐排序**（综合考虑我的领域、地区及是否已报名），显示 `剩余 N 个名额`（报名人数少于招募人数、入选率较高的活动）、`我的领域`、`我的地区`、`已报名` 等徽标 / 可按最新、临近截止、积分排序，并支持按行业、地区筛选
- 无需登录即可查看的公开目录（luby.im/c，含 EN、CN 版本）同样支持 **临近截止、最新、积分** 排序及频道、地区筛选
- 概览首页展示 **“适合我的活动”** 3 个 · 本周新增活动数 · 当 **我的领域活动将在 48 小时内截止** 时，早晨会收到提醒
- **新活动即时提醒**：当符合我的专业领域（或我的活动地区 + 我已有的频道）的活动开始招募时，会立即收到通知/推送/邮件（每天最多 1 条，其余汇总在周一的摘要中发送）。专业领域、地区、频道信息填写得越完整，推送就越精准；可在 `设置 → 邮件通知` 的 **提醒与推荐** 中关闭该功能。
- 活动详情：按频道展示任务内容、提供事项、招募期限、积分、广告主资料链接
- 活动详情页右侧的 **入选可能性** 卡片：展示竞争比率（报名人数/招募人数，距离截止天数）、我的领域/地区/频道是否匹配、过往完成记录，并给出高/中/低等级及改善建议（如注册频道、添加领域、完善报名留言）。该结果仅供参考，最终入选由广告主决定

## 4. 报名与邀请

![公开活动页面 — 积分、招募截止时间、注册并报名](/docs-img/campaign.jpg)
1. 在活动详情页点击 **报名** → 填写报名留言（可选）。点击 **AI 草稿** 按钮，系统会根据活动任务和我的资料自动生成 2～3 句内容（可编辑）。若竞争激烈，可用具体的策划方案来突出差异化，并以自己已有的频道为核心撰写，切勿虚构未注册的频道或不存在的经历。在 Luby AI 完成的体验次数可作为可信度依据写入
2. 处于报名待定状态时可 **取消报名**。不能对同一活动重复报名
3. 若广告主发出邀请，可在 `控制台 → 收到的邀请` 中 **接受（自动报名）** 或 **拒绝**
4. 一旦入选，会收到通知及邮件 → 可在与广告主的 **聊天**（`控制台 → 消息`）中协调安排日程

## 5. 体验 → 内容提交 → 审核 — `控制台 → 我的报名`
1. 按照入选活动的任务要求发布内容（**必须标注 #广告 #赞助等经济利益说明**）
2. **提交内容**：填写发布链接 + 备注 → 等待广告主审核
3. **审核通过** → 积分立即到账 / **要求修改** → 查看反馈 → 在同一页面 **重新提交**
4. 体验结束后若未提交内容，系统会发送提醒

## 6. 积分与提现 — `控制台 → 积分`
- **持有积分**（1P = 1 韩元）· **积分明细**：内容审核通过（+活动名称）、推荐奖励、提现、提现待处理、提现被拒等记录按时间顺序显示
- **申请提现**：最低 10,000P，填写银行、账户、开户人姓名 → 申请后立即扣除 → 经运营人员确认后发放（如被拒绝则自动退回并显示原因）

## 7. 公开资料·好友推荐
- 打开 `设置 → 公开资料` 开关 → 获得 `luby.im/p/我的ID` 链接（支持 KR/EN/CN）— 仅显示姓名、照片、简介、地区、领域、频道、已完成合作项目（邮箱、联系方式、结算信息不公开）。可发送给广告主或海外品牌作为作品集展示
- 在 `控制台 → 我的作品集` 中可保存为 PDF，并 **打印为 A4 格式的二维码名片**（每张 A4 可印 10 张 90×55mm 规格名片），扫描二维码即可打开我的公开资料（需开启公开资料功能）。可在店铺拜访、活动、快闪店现场直接递交给商家
- 开启公开资料后，**我的作品集** 页面顶部会显示资料浏览量（总访问数、独立访问数、最近 7 天）及流量来源（二维码名片 / 作品集链接 / 直接访问·搜索）。访问者仅通过每日变化的哈希值区分，不会存储个人信息，且不包含我本人的浏览记录
- 在首页 **邀请好友得 500P** 卡片中复制并分享我的推荐链接（luby.im/creators?ref=…），可查看注册、奖励及本月次数。也可在活动详情页点击 **分享给朋友** → 复制该活动专属推荐链接（?ref）。通过链接注册的朋友 **完成首次体验后可获得 500P**（每月最多 5 人）。可在概览首页的“我的推荐注册”中查看详情

## 8. 通知 · 像App一样使用
- 应用内通知 + 邮件通知（进度通知/提醒与推荐分别可开关，位于 `设置 → 邮件通知`）
- 在手机浏览器中打开 luby.im → 选择 **添加到主屏幕** → 像App一样启动（可快速进入活动、我的报名、通知）

## 9. 常见问题
- **审核未通过** → 请确认频道链接是否为真实资料页面，简介、领域信息是否已填写完整。若等待超过 24 小时，请联系 contact@plander.io
- **看不到报名按钮** → 可能是尚未通过审核，或该活动招募已截止
- **积分未到账** → 积分将在广告主审核通过后入账。请在我的报名中查看状态（已提交/要求修改/已通过）

### 每周摘要
每周**周一上午 9 点**，系统会以一条通知/邮件的形式发送：我的领域及地区新开放的活动、本周即将截止的活动、待报名/需提交/待审核的数量、上周通过并入账的积分，以及（若开启公开资料）上周我的资料浏览量和二维码名片流量、是否可提现等信息。可在设置 > 邮件接收设置的**摘要**选项中关闭该功能。

### 推送通知
在设置 > **推送通知 > 在此设备上开启** 中打开后，即使关闭应用，也能第一时间在设备上收到入选、审核通过、截止提醒等通知（邮件接收设置中的分类同样适用于推送）。Android 及 PC Chrome 可直接开启，**iPhone 需通过 Safari 的分享 → 添加到主屏幕 安装 Luby AI 应用后**再开启。可按设备分别开启或关闭。

### 我的作品集（PDF）
在菜单 > **我的作品集** 中，可以以作品集形式展示我的资料、频道、领域及合作履历给品牌方查看，并可 **保存为 PDF、打印**。即使公开资料功能关闭，本人也可查看；开启后可通过链接（`luby.im/p/…`）分享相同页面。
