# Luby AI 创作者手册

> 适用对象：报名参与活动、体验产品并发布内容后获得积分的创作者 · 최종 갱신 2026-08-19 · https://luby.im

> 注册前须知页面：**luby.im/creators**（EN: /en/creators, CN: /zh/creators）——无需登录即可查看当前招募中的活动数量、剩余名额及积分水平和操作方式。分享给朋友时请使用此链接。

## 1. 注册与审核

> **语言**：注册、登录、密码页面支持韩语、English、中文。点击屏幕右上角的 **KR / EN / CN** 切换语言后会记住选择，若从英文、中文活动页面进入，则直接以对应语言打开。登录后，主页（概览、今日待办、推荐活动）、菜单、浏览活动（列表、筛选）、活动详情、报名、我的报名（内容提交）均以相同语言显示，英文、中文用户查看的活动标题、内容也是翻译版本。设置（渠道、专业领域、公开资料、通知）、收到的邀请、积分·提现、消息、作品集等创作者所有页面均以相同语言显示。应用内通知、推送、邮件通知也以相同语言发送（广告主亲自撰写的消息、邀请内容保持原文）。
1. 在 https://luby.im/signup 选择**创作者**（或点击“使用 Google/Kakao 继续”→ 在引导流程中选择创作者）
2. 填写姓名/昵称、活动地区、主要渠道（URL）、专业领域（最多 3 个）→ 注册 → **邮箱验证**
3. 运营人员审核渠道与资料后予以**批准**（通常 24 小时内完成）。收到批准通知或邮件后即可报名。批准前也可以浏览活动。

## 2. 完善个人资料 — `控制台 → 设置`
将概览主页及设置页面顶部的**资料完整度**仪表调整至 100%。完整度越高，被推荐、被邀请的机会越多。

| 项目 | 位置 | 提示 |
|---|---|---|
| SNS 渠道 (30%) | 设置 → 渠道 (`#channels`) | 选择渠道类型后，URL、账号示例会相应变化。**小红书**的账号即 App 个人主页中的 `小红书号`，URL 为个人主页分享链接（可使用 xhslink 短链接）· 抖音为 `抖音号` · Lemon8 为 `lemon8-app.com/@…`。与所选渠道类型不符的地址将无法保存 |
| 专业领域 (25%) | 设置 → 专业领域 (`#categories`) | 最多 3 个。属于我的领域的活动会被优先推荐 |
| 粉丝数 (15%) | 按渠道输入 | 用于广告主筛选及预估触达计算 |
| 一句话简介 (15%) | 设置 | 广告主选择创作者时最先阅读的一句话（10 字以上）|
| 活动地区 (10%) · 头像 (5%) | 设置 | 用于基于地区的推荐 · 有头像的资料被选中概率更高 |

## 3. 查找活动 — `控制台 → 活动`

![活动目录——渠道/排序筛选与剩余名额徽章](/docs-img/directory.jpg)
- 默认按**推荐排序**（综合我的领域、地区、是否报名过）排列，带有 `仅剩N个名额`（报名人数少于招募人数、入选概率较高的活动）`我的领域` `我的地区` `已报名` 徽章 / 可按最新发布、截止临近、积分排序，并支持按行业、地区筛选
- 无需登录即可浏览的公开目录（luby.im/c，含 EN、CN 版本）也支持**截止临近、最新发布、积分**排序及渠道、地区筛选
- 概览主页展示 **“适合我的活动”** 3 个 · 本周新增活动数量 · 若**我的领域活动将在 48 小时内截止**，会收到早间提醒
- **新活动即时提醒**：当符合我的专业领域（或我的活动地区+我拥有的渠道）的活动开始招募时，会立即收到通知、推送及邮件提醒（每天最多 1 条，其余汇总至周一摘要）。填写的专业领域、地区、渠道越完整，推送越精准，可在 `设置 → 邮件通知` 的**提醒与推荐**中关闭。
- 活动详情：任务（按渠道）、提供内容、招募周期、积分、广告主资料链接
- 活动详情右侧的**入选可能性**卡片：显示竞争比例（报名数/招募数、剩余天数）、我的领域/地区/渠道匹配情况、完成历史，并给出高/中/低等级及补充建议（注册渠道、添加领域、报名留言）。该评估仅供参考，最终是否入选由广告主决定

## 4. 报名 · 邀请

![公开活动页面——积分、招募截止日期及注册并报名](/docs-img/campaign.jpg)
1. 在详情页点击**报名** → 填写报名留言（可选）。点击 **AI 草稿**按钮，系统会根据活动任务与我的资料自动生成 2～3 句内容（可修改）。竞争激烈时应通过具体的策划内容形成差异化，围绕自己实际拥有的渠道撰写，切勿编造未注册的渠道或不存在的经历。在 Luby AI 完成的体验次数可作为信任依据写入
2. 报名审核期间可**取消报名**。同一活动不可重复报名
3. 若广告主发出邀请，可在 `控制台 → 收到的邀请` 中选择**接受（自动报名）** / 拒绝
4. 入选后会收到通知及邮件 → 可通过**聊天**（`控制台 → 消息`）与广告主协调日程

## 5. 体验 → 内容提交 → 审核 — `控制台 → 我的报名`
1. 按活动任务要求发布内容（**须标注 #广告 #赞助等经济利益说明**）
2. **提交内容**：填写发布链接+备注 → 提交给广告主审核
3. **通过** → 积分立即到账 / **要求修改** → 查看反馈 → 在同一页面**重新提交**
4. 体验期结束后若未提交内容，系统会发送提醒

## 6. 积分与提现 — `控制台 → 积分`
- **持有积分**（1P = 1韩元）· **积分明细**：按时间顺序显示内容通过（+活动名称）、推荐奖励、提现、提现处理中、驳回等记录
- **申请提现**：最低 10,000P 起，填写银行、账号、账户持有人信息 → 申请即时扣除积分 → 经运营人员确认后发放（若被驳回，积分自动退回并显示原因）

## 7. 公开资料 · 好友推荐
- 打开 `设置 → 公开资料` 开关 → 生成链接 `luby.im/p/我的ID`（支持 KR/EN/CN）——仅显示姓名、照片、简介、地区、领域、渠道、已完成合作信息（邮箱、联系方式、结算信息均不公开）。可发送给广告主、海外品牌作为作品集展示
- 在 `控制台 → 我的作品集` 中可保存为 PDF，并**打印 QR 名片（A4）**——一张 A4 纸可打印 10 张标准名片尺寸（90×55mm），扫描二维码即可打开我的公开资料（需开启公开资料）。可在到店拜访、活动、快闪店等场合直接递交给商家
- 开启公开资料后，**我的作品集**页面顶部会显示资料浏览次数（总浏览、独立访客、近 7 天）及来源渠道（QR名片 / 作品集链接 / 直接访问·搜索）。访客仅通过每日变化的哈希值区分，不保存任何个人信息，本人查看的浏览记录不计入统计
- 在主页的**邀请好友得 500P**卡片中可复制并分享我的专属推荐链接（luby.im/creators?ref=…），查看注册情况、奖励及本月次数。在活动详情页点击**分享给朋友** → 复制该活动专属推荐链接（?ref）。通过该链接注册的朋友**首次完成体验后可获得 500P**（每月最多 5 人）。可在概览主页的“我的推荐注册”中查看

## 8. 通知·像应用一样使用
- 应用内通知 + 邮件通知（进度通知 / 提醒·推荐可分别开关，位于 `设置 → 邮件通知`）
- 在手机浏览器中打开 luby.im → 点击**添加到主屏幕** → 即可像应用一样使用（快捷入口：活动、我的报名、通知）

## 9. 常见问题
- **一直未通过审核** → 请确认渠道链接是否为真实主页，简介、领域信息是否已填写完整。若等待超过 24 小时，请联系 contact@plander.io
- **看不到报名按钮** → 该活动尚未通过审核或招募已截止
- **积分没有到账** → 需经广告主审核通过后才会到账。请在“我的报名”中查看状态（已提交/要求修改/已通过）

### 每周摘要
每周**周一上午 9 点**，您将通过一条通知或邮件收到：我的领域、地区内新开放的活动、本周截止活动、待审核报名/需提交内容/待审核内容数量、上周通过并到账的积分、（若已开启公开资料）上周我的资料浏览次数及 QR 名片访问情况，以及是否可提现。可在“设置 > 邮件接收设置”的**摘要**选项中关闭。

### 推送通知
在“设置 > **推送通知 > 在此设备上开启**”中开启后，即使应用未打开，入选、通过、截止等通知也会直接推送到设备上（邮件接收设置中的分类同样适用于推送）。Android 与 PC 上的 Chrome 可直接开启，**iPhone 需通过 Safari 的“共享”→“添加到主屏幕”安装 Luby AI 应用后方可开启**。可按设备分别开启或关闭。

### 我的作品集（PDF）
在菜单中点击**我的作品集**，即可以作品集形式查看向品牌展示的个人资料、渠道、领域及合作历史，并可**保存为 PDF 或打印**。即使公开资料处于关闭状态，本人仍可查看；开启后可通过链接（`luby.im/p/…`）分享同一页面。
