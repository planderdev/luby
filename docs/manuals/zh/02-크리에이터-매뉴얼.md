# Luby AI 创作者手册

> 对象：应募活动、体验并发布内容后获得积分的创作者 · 最终更新 2026-08-19 · https://luby.im

> 注册前须知页面：**luby.im/creators**（EN: /en/creators, CN: /zh/creators）— 无需登录即可查看当前正在招募的活动数量、剩余名额和积分水平、进行方式。发给朋友时请使用此链接。

## 1. 注册与审核

> **语言**：注册·登录·密码页面支持韩语·English·中文。点击画面右上角的 **KR / EN / CN** 切换后会记住所选语言，若从英文·中文活动页面进入，会直接以该语言打开。登录后，首页（概览·今日待办·推荐活动）、菜单、活动浏览（列表·筛选）、活动详情、应募、我的应募（内容提交）都会以相同语言显示，英文·中文用户看到的活动标题·内容也是翻译版本。设置（渠道·专业领域·公开资料·通知）、收到的邀请、积分·提现、消息、作品集等创作者界面全部以相同语言显示。应用内通知·推送·邮件通知也会以相同语言接收（广告主本人撰写的消息·邀请内容保持原文）。
1. 在 https://luby.im/signup 选择 **创作者**（或通过 Google/Kakao 继续 → 在引导流程中选择创作者）
2. 输入姓名·昵称、活动地区、代表渠道（URL）、专业领域（最多3个）→ 注册 → **邮箱验证**
3. 运营人员审核渠道·资料后进行**审核通过**（通常在24小时内）。收到审核通过通知·邮件后即可应募。审核通过前也可以浏览活动。

## 2. 完善资料 — `控制台 → 设置`
请将概览首页和设置页面顶部的**资料完成度**仪表提升至100%。完成度越高，获得推荐和邀请的机会越多。

| 项目 | 位置 | 提示 |
|---|---|---|
| 社交媒体渠道 (30%) | 设置 → 渠道 (`#channels`) | 选择渠道类型后，URL·账号示例会随之变化。**小红书**以应用资料中的 `小红书号` 作为账号，URL为资料分享链接（支持 xhslink 短链接）· Douyin（抖音）为 `抖音号` · Lemon8 为 `lemon8-app.com/@…`。与渠道类型不符的地址将无法保存 |
| 专业领域 (25%) | 设置 → 专业领域 (`#categories`) | 最多3个。我的领域相关活动会优先被推荐 |
| 粉丝数 (15%) | 按渠道输入 | 用于广告主筛选和预估触达计算 |
| 一句话简介 (15%) | 设置 | 广告主在挑选时最先阅读的一句话（10字以上） |
| 活动地区 (10%) · 头像照片 (5%) | 设置 | 基于地区的推荐 · 有照片的资料被选中的概率更高 |

## 3. 查找活动 — `控制台 → 活动`

![活动目录 — 渠道·排序筛选与剩余名额徽章](/docs-img/directory.jpg)
- 默认排序为**推荐排序**（综合我的领域·地区·是否应募）、`剩余N个名额`（应募人数少于招募人数、入选概率较高的活动）`我的领域` `我的地区` `已应募` 徽章 / 最新排序·截止临近排序·积分排序，以及行业·地区筛选
- 无需登录即可浏览的公开目录（luby.im/c，含英文·中文版本）同样支持**截止临近排序·最新排序·积分排序**及渠道·地区筛选
- 概览首页展示**“为我推荐的活动”**3个 · 本周新增活动数 · **若我的领域活动将在48小时内截止**，会在早晨收到提醒
- **新活动即时通知**：当符合我的专业领域（或我的活动地区+我所拥有的渠道）的活动开始招募时，会立即收到通知·推送·邮件（每天最多1条，其余汇总在周一摘要中发送）。专业领域·地区·渠道信息填写得越完整，推送会越精准，可在 `设置 → 邮件通知` 的**提醒·推荐**中关闭该功能。
- 活动详情：任务说明（按渠道）·提供内容·招募期限·积分·广告主主页链接
- 活动详情页右侧的**入选可能性**卡片会显示竞争比例（应募数/招募数·倒计时天数）、我的领域·地区·渠道匹配情况、完成记录，并给出高/中/低等级及改进建议（登记渠道·添加领域·完善应募留言）。此为参考性预估，最终入选由广告主决定

## 4. 应募 · 邀请

![公开活动页面 — 积分·招募截止·注册并应募](/docs-img/campaign.jpg)
1. 在详情页点击**应募**→ 填写应募留言（可选）。点击 **AI草稿**按钮，系统会根据活动任务和我的资料自动生成2~3句内容（可修改）。竞争激烈时应以具体的策划方案突出差异化，内容应围绕我拥有的渠道撰写，切勿虚构未登记的渠道或不存在的经历。在 Luby AI 完成的体验数量可作为信誉依据写入
2. 处于应募等待状态时可**取消应募**。同一活动不可重复应募
3. 若广告主发出邀请，可在 `控制台 → 收到的邀请` 中选择**接受（自动应募）** / 拒绝
4. 入选后会收到通知·邮件 → 可通过与广告主的**聊天**（`控制台 → 消息`）协调日程

## 5. 体验 → 提交内容 → 审核 — `控制台 → 我的应募`
1. 按入选活动的任务要求发布内容（**必须标注 #广告 #赞助等经济利益关系**）
2. **提交内容**：发布链接 + 备注 → 广告主审核
3. **审核通过** → 积分立即到账 / **要求修改** → 查看反馈 → 在同一页面**重新提交**
4. 体验结束后若未提交内容，将收到提醒

## 6. 积分与提现 — `控制台 → 积分`
- **持有积分**（1P = 1韩元）· **积分明细**：内容审核通过（+活动名称）· 推荐奖励 · 提现 · 提现中 · 驳回，按时间顺序展示
- **申请提现**：最低10,000P，输入银行·账户·开户人信息 → 申请即时扣除 → 运营人员确认后发放（驳回时自动退还并显示原因）
- **提现账户**：目前**仅支持韩国银行账户**提现（不支持境外账户）。海外创作者主要以体验提供的物品·产品本身作为主要回报，待拥有韩国账户后即可提现积分。

## 7. 公开资料 · 好友推荐
- 开启 `设置 → 公开资料` 开关 → 生成 `luby.im/p/我的ID` 链接（KR/EN/CN）— 仅展示姓名·照片·简介·地区·领域·渠道·完成的合作项目（邮箱·联系方式·结算信息不公开）。可作为作品集发送给广告主·海外品牌
- 在 `控制台 → 我的作品集` 中可保存为PDF，**打印QR名片 A4纸张** → 一张A4可印出10张标准名片尺寸（90×55mm），扫描QR码即可打开我的公开资料（需开启公开资料）。可在店铺拜访·活动·快闪店中直接递交给店主
- 开启公开资料后，**我的作品集**页面顶部会显示资料访问次数（总访问·独立访客·近7天）及访问来源（QR名片 / 作品集链接 / 直接访问·搜索）。访客仅通过每日变化的哈希值区分，不保存个人信息，本人查看的访问记录不计入统计
- 在首页**邀请好友得500P**卡片中可复制·分享我的推荐链接（luby.im/creators?ref=…），并查看注册情况·奖励·本月次数。在活动详情页点击**分享给好友** → 复制该活动专属推荐链接（?ref）。通过链接注册的朋友**完成首次体验后可获得500P**（每月最多5人）。可在概览首页的“我的推荐注册”中查看

## 8. 通知·像应用一样使用
- 应用内通知 + 邮件（进度通知 / 提醒·推荐可分别开关，位于 `设置 → 邮件通知`）
- 在移动浏览器中打开 luby.im → **添加到主屏幕** → 像应用一样运行（快捷方式：活动·我的应募·通知）

## 9. 常见问题
- **审核一直未通过** → 请确认渠道URL是否为真实资料页面、简介·领域是否已填写完整。若等待超过24小时，请联系 contact@plander.io
- **看不到应募按钮** → 该活动可能尚未审核通过，或招募已截止
- **积分没有到账** → 需经广告主审核通过后才会到账。请在我的应募中查看状态（已提交/要求修改/已通过）

### 每周摘要
每周**周一上午9点**，您会通过一条通知·邮件收到：我的领域·地区新开放的活动、本周截止活动、待应募·需提交·待审核的件数、上周审核通过及到账积分、（若开启公开资料）上周我的资料访问次数与QR名片访问来源，以及是否可提现。可在设置 > 邮件接收设置的**摘要**中关闭该功能。

### 推送通知
在设置 > **推送通知 > 在此设备开启**中点击后，即使关闭应用，入选·审核通过·截止提醒也会直接推送到设备（邮件接收设置中的分类同样适用于推送）。Android·PC Chrome可直接开启，**iPhone需通过Safari分享 → 添加到主屏幕安装Luby AI应用后**开启。可按设备分别开启或关闭。

### 我的作品集（PDF）
在菜单 > **我的作品集**中，可将我的资料·渠道·领域·合作历史以作品集形式展示给品牌方，并可**保存为PDF·打印**。即使公开资料处于关闭状态，本人也可查看；开启后可通过链接（`luby.im/p/…`）分享同一页面。
