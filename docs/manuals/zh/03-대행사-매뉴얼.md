# Luby AI 营销代理・执行公司手册

> 适用对象：代替多个客户运营体验团活动的代理商 · 최종 갱신 2026-08-19 · 与[广告主手册](01-광고주-매뉴얼.md)中的功能完全相同

## 1. 以代理商身份注册
- 注册时在广告主类型中选择**营销代理・执行公司** → 商号一栏会变为**代理商名称**。请填写代理商的营业执照注册号
- 如果已以品牌身份注册，可在 `设置 → 广告主类型` 中进行修改。个人资料・运营者页面会显示"代理商"标识

## 2. 按客户运营活动
- 活动的**商号（business_name）需按每个活动单独填写** → 可在同一账户・同一控制台中管理客户 A/B/C 的活动
- **复制**：详情页 → "以此活动新建" → 渠道・任务・提供内容・日程会自动预填 → 只需修改客户商号和招募期限即可提交审核申请
- 在**全部交给 AI**中只需输入一行客户所属行业信息（位置・客户群・核心产品・目标国家）即可生成初稿

## 3. 达人招募
- `寻找达人`：可按行业・地区・渠道・粉丝数・排序进行筛选，并提供快捷筛选 **Xiaohongshu / Douyin / Lemon8 / 有公开资料**
- 若需将候选人分享给客户，请使用达人详情页中的**公开资料链接**（仅限已选择公开选项的达人）
- BUSINESS：AI 匹配（匹配度・理由）→ 邀请，选定后可进行聊天

## 4. 风险管理与报告
- 提交审核申请时，运营者可参考 **AI 事前检查**（广告标识遗漏・效果夸大・不当要求等）来进行批准/驳回 — 若提前在任务中加入 `#广告 #赞助` 标识，可减少被驳回的情况
- 客户报告：活动效果卡片（转化漏斗・各渠道触达情况）、活动完成时的**效果报告通知**、活动列表中的效果标签、公开活动页面链接（KR/EN/CN）

## 5. 套餐方案
- 若需同时运营多个客户的活动，需使用 **BUSINESS**（活动数量不限・AI 全套功能・应征者不限・聊天功能）及以上套餐。如需大规模运营・API 接口・专属客户经理服务，请咨询 ENTERPRISE 方案（contact@plander.io）
