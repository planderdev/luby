💡 각 카드마다: 제목 복사 → Supabase의 Subject heading 칸 클릭 → ⌘A → ⌘V  |  본문 HTML 전체 복사 → Supabase의 Message body 코드 칸 클릭 → ⌘A → ⌘V  |  Save changes
버튼이 초록색 복사됨 ✓으로 바뀌면 클립보드에 들어간 겁니다.
